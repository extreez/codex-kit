# Синтетическое исследование (claude-persona)

Тонкая обёртка. Апстрим — самостоятельный плагин Codex со своей
Python-инфраструктурой (`pandas`, `matplotlib`, `seaborn`), скриптами
генерации и анализа, отдельными `claude -p`-субпроцессами на персону.
Код не копируется в этот блок — ставится апстрим целиком.

## Что это

Каждая персона отвечает в изолированном subprocess (`claude -p
--safe-mode`, структурированный вывод через `--json-schema`) — без
взаимного смещения между персонами и без утечки контекста проекта.
Каждый прогон фиксирует стоимость и точные ID моделей.

Для маркетологов и продакт-менеджеров, которым нужен быстрый
качественный сигнал до полевого исследования: концепт-тесты,
тестирование мессаджинга, упаковки, фичебандлов.

## Установка

```bash
/plugin marketplace add takechanman1228/claude-persona
/plugin install claude-persona@claude-persona
```

Перезапустить Codex после установки. Альтернатива — одна
curl-команда:

```bash
curl -fsSL https://raw.githubusercontent.com/takechanman1228/claude-persona/main/install.sh | bash
```

Требует Python 3.10+ и пакеты `pandas`, `matplotlib`, `seaborn` для
пайплайна анализа — устанавливаются апстримом, не этим блоком.

## Три команды скилла

**`/persona generate N <описание аудитории>`** — построить панель из N
разнообразных персон. Пример: `/persona generate 10 Gen Z skincare
shoppers in the US`.

**`/persona ask <вопрос>`** — задать вопрос всей панели, получить
темы/паттерны ответов. Пример: `/persona ask Что вас больше всего
фрустрирует при выборе продукта?`.

**`/persona concept-test <описание концептов>`** — сравнить несколько
концептов/сообщений/тарифов, получить доли первого выбора и purchase
intent по каждой персоне. Пример: сравнение 3 концептов продукта с
разбивкой по долям выбора (%) и intent 1-5.

## Предупреждение

Апстрим — не текстовый скилл, а полноценная Python-инфраструктура:
`install.sh`/`uninstall.sh`, зависимости, генерируемые `personas/` и
`outputs/` в рабочей директории. Ставить и обновлять его отдельно от
`codex-kit`, следить за апстримом напрямую.

Результат — синтетический сигнал, не замена реальным респондентам.
Апстрим сообщает 84-100% воспроизводимости персон между моделями и
100% воспроизводимость на повторных прогонах Fable — но это
согласованность симуляции с собой, не гарантия совпадения с реальным
рынком. Использовать для быстрой направляющей проверки гипотез перед
дорогим полевым исследованием, не вместо него.
