# Библиотека звуковых эффектов

На kie.ai генератора звуковых эффектов нет - только синтез речи и изоляция
голоса, проверено. Эффекты берутся из локальной библиотеки, а не
генерируются.

## Где лежит

`C:\Users\supga\sfx-library\` - общая папка на машину, не внутри отдельного
проекта. Проектная копия дублирует файлы: пять роликов дают пять одинаковых
папок со звуками. Внутри подпапки по категориям: `impact/`, `whoosh/`,
`ambience/`, `ui/`, `foley/`, `music-hit/`.

## Манифест

`manifest.json` в корне библиотеки, один объект на файл:

```json
{
  "file": "impact/thud-deep-01.wav",
  "tags": ["impact", "deep", "low"],
  "duration_ms": 800,
  "category": "impact",
  "source": "Freesound, автор user123",
  "license": "CC0"
}
```

## Как искать

Фильтр по `tags` и `category` в `manifest.json`, без отдельной базы данных.
Например нужен звук удара короче секунды - выбрать записи с
`category: "impact"` и `duration_ms` меньше 1000.

## Как добавлять новый звук

Положить файл в подпапку нужной категории, добавить запись в
`manifest.json` со всеми полями. Запись без источника или без лицензии не
считается завершённой - файл в таком виде в библиотеку не принимается.

## Второй способ: ElevenLabs SFX

Когда в библиотеке нужного звука нет - генерация через ElevenLabs SFX
прямым ключом. Перед вызовом скилл проверяет наличие ключа. Нет ключа
значит сказать об этом и предложить искать замену в библиотеке вместо
генерации. Сгенерированный звук кладётся в библиотеку с записью в
манифесте (источник: ElevenLabs SFX, лицензия - по условиям аккаунта
пользователя), чтобы не платить за него второй раз.

## Лицензии

У каждого файла в манифесте записаны источник и лицензия. Звук без
записанной лицензии в ролик не идёт, даже если он уже лежит в папке.
