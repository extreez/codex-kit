# Переходы

Каталог переходов - HyperFrames, ставится как есть, переходы уже в нём.
Этот документ не описывает сам каталог. Здесь только пресеты: числа поверх
готовых переходов и когда какой брать.

## Пресеты

| Имя | Длительность | Кривая | Когда уместен |
|---|---|---|---|
| Жёсткая склейка | 0 мс | без кривой | умолчание, диалоги, быстрый темп |
| Кроссфейд | 400 мс | ease-in-out | смена времени или локации без потери ориентации |
| Вспышка | 120 мс | линейная, пик яркости в середине | акцент на ударный момент, смена сцены на бит |
| Свип | 250 мс | ease-out | переход между параллельными сценами через направленное движение в кадре |
| Увеличение | 300 мс | ease-in | переход в крупный план, акцент на детали |
| Свист | 200 мс | ease-in-out, с motion blur | быстрая смена локации, экшн-монтаж |
| Затемнение | 600 мс | линейная | конец сцены, финал акта, скачок во времени |
| Склейка по движению | 0 мс | без кривой | продолжение траектории движения из кадра в кадр |
| Склейка по совпадению формы | 0 мс | без кривой | визуальная рифма между похожими по форме объектами на стыке кадров |

## Как добавить свой

Пресет - это длительность и кривая поверх перехода, который уже есть в
каталоге HyperFrames, не новый переход. Чтобы добавить пресет: найти
подходящий переход в каталоге HyperFrames, подобрать длительность и кривую
под задачу, вписать строку в таблицу выше с именем, длительностью, кривой
и условием, когда переход уместен.

## Правило

Жёсткая склейка - умолчание. Переход добавляется, когда есть причина, а не
для красоты. Ролик, где каждая склейка с эффектом, читается хуже ролика
без переходов вовсе.
