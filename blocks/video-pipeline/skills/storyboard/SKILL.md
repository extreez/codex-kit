# storyboard

Скилл собирает раскадровку на одном холсте Claude Design: каждый план -
отдельный артборд, пользователь правит мышью. Не генерирует финальные
шоты сам - только готовит артборды планов и передаёт их дальше после
утверждения.

## Что на артборде плана

| Поле | Содержание |
|---|---|
| Номер | порядковый номер плана в ролике |
| Длительность | секунды из `script.md` |
| Крупность | общий, средний, крупный план |
| Кадр | что в кадре |
| Камера | движение камеры, если есть |
| Текст на экране | если есть |
| Звук | что звучит в этот момент |
| Исходник | ссылка на кадр, скетч или промпт генерации |

## Откуда берётся картинка плана

Три способа, все допустимы:

- генерация на kie.ai через creative-skill
- кадр из уже снятого материала
- рисунок или скетч от руки

## Раскадровка сужается до недостающих планов

Если материал уже отснят, раскадровываются только вставки - планы,
которых в отснятом материале нет. Не пересобирать раскадровку всего
ролика заново, если часть планов уже покрыта съёмкой.

## Что после утверждения

Раскадровка - стоп-точка. После утверждения артбордов список планов идёт
в `/hyperframes-keyframes` и creative-skill - они делают ключевые кадры,
затем генерацию шотов по каждому плану.

## Жёсткие правила

Длительности планов в сумме равны сценарию, без расхождений.
Ни один план не уходит в генерацию без утверждения раскадровки целиком.
Не генерировать картинки планов, пока структура раскадровки не
согласована - генерация платная, черновые правки делаются на артбордах,
не перегенерацией.

## Соседние скиллы

`script` перед `storyboard` - без утверждённого сценария длительности
планов посчитать не из чего. После утверждения - `/hyperframes-keyframes`
и creative-skill для ключевых кадров и генерации шотов.
