# Бесшовные лупы

Скилл закрывает два смысла слова «луп»: бесшовный клип, который крутится
вечно без видимого шва, и библиотеку переиспользуемых кусков видео.
Луп под конкретную площадку (Instagram, TikTok) отдельным режимом не
делается - он получается сам, если исходный клип уже бесшовный.

## Три способа сделать бесшовность

| Способ | Как | Когда работает |
|---|---|---|
| Честный | Генерация с одинаковым первым и последним кадром. У части моделей kie.ai есть поле конечного кадра, смотреть `limits.inputFiles` в карточке модели. | Лучшее качество, но не все модели умеют. |
| Кроссфейд | Последние 0.5 секунды клипа микшуются в первые 0.5 секунды. | Дёшево. Работает, когда в кадре нет резкого движения. |
| Зеркало | Клип плюс он же задом наперёд. | Всегда стыкуется, но на любом направленном движении виден «пинг-понг». Годится для абстракций. |

Выбор способа зависит от модели и содержимого кадра, не от удобства. Честный
способ - первый кандидат, если модель его поддерживает.

## Проверка обязательна

Луп не считается готовым по впечатлению агента. Скрипт `scripts/loop_check.py`
сравнивает первый и последний кадр двумя метриками сразу. Скилл обязан вызвать
эту проверку на каждом лупе и передать её результат дальше, не подменяя его
собственной оценкой.

| Метрика | Что ловит | Порог по умолчанию |
|---|---|---|
| dHash, расстояние Хэмминга | расхождение рисунка внутри кадра | 8 из 64 |
| среднее отличие цвета на миниатюре 8x8 | смену цвета и яркости | 12 из 255 |

Обе обязательны. Одного dHash мало: он строит биты по перепадам яркости
внутри кадра, поэтому у ровной заливки хеш нулевой независимо от цвета.
Клип, уезжающий с синего экрана на красный, по одному dHash прошёл бы как
бесшовный.

```bash
python scripts/loop_check.py out/loop.mp4
```

Код выхода 0 значит принят, 1 значит шов виден. Вывод называет, что именно
разошлось: рисунок, цвет или обе вещи. Пороги двигаются флагами
`--threshold` и `--color-threshold`, но двигать их ради того, чтобы луп
прошёл, запрещено.

## Библиотека кусков

Хранилище: `loop-library/` рядом с проектами, общее на все проекты пайплайна.
Внутри подпапки по типу: `transitions/`, `flashes/`, `titles/`, `frames/`.
Имя файла: `<тип>-<описание>-<вариант>.mp4`, например
`flash-white-06.mp4`, `transition-swipe-left.mp4`.

Манифест `manifest.json` в корне библиотеки, один объект на элемент:

```json
{
  "name": "flash-white-06.mp4",
  "tags": ["flash", "white", "fast"],
  "duration_ms": 600,
  "resolution": "1920x1080",
  "fps": 30,
  "transparent": false,
  "source": "проект storefront-promo, 2026-01-12"
}
```

Поиск по библиотеке - фильтр по `tags` и `resolution` в этом JSON, без
отдельной базы данных.

## Жёсткие правила

Луп без прохождения `loop_check.py` не сдаётся, даже на вид ровный.
Зеркальный луп не выдаётся за честный - способ записывается вместе с
результатом. Разрешение и частоту кадров элемента библиотеки записывать
всегда - без них элемент не встанет ровно в таймлайн другого проекта.

## Соседние скиллы

До: генерация шотов через creative-skill, если под луп нужен новый
исходный клип. После: сборка композиции HyperFrames - готовый луп
вставляется как обычный клип с зацикленным повтором на таймлайне.
