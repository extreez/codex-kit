# route

Скилл собирает список шагов пайплайна, у которых есть вход, и показывает
его пользователю до запуска. Не выбирает один сценарий работы из готового
набора - один проект может одновременно иметь снятый материал и требовать
догенерации графики, тогда работают и шаги монтажа, и шаги генерации.
Шаг без входа не запускается и не появляется в списке как активный.

## Шаг 0. Проверить, чем работать

Блок своего движка не несёт. Если внешнего инструмента нет, шаг, который
на нём стоит, надо пометить не как «пропущен по входу», а как
«заблокирован, инструмента нет». Это разные вещи, путать их нельзя.

```bash
bash apps/video-stack/check.sh
```

Код выхода 0 или 2 значит можно работать. Код 1 значит не хватает
обязательного, конвейер не поедет.

Что на чём стоит:

| Шаг | Чем работает | Как поставить |
|---|---|---|
| сборка, моушн, титры, звук, рендер | HyperFrames | `npx skills add heygen-com/hyperframes` |
| autocut, субтитры, цвет | video-use | `git clone https://github.com/browser-use/video-use`, внутри `uv sync`, дальше symlink по его `install.md` |
| `word-timing` локально | whisper.cpp | см. скилл `word-timing`, там точные файлы |
| генерация кадров и шотов | creative-skill плюс gcv-kie-cli | ключ `KIE_API_KEY` |
| `watch` в глубоком режиме | Gemini Files API | ключ `GEMINI_API_KEY` |
| `previz` | Blender MCP | ставится, только когда нужен |

Инструмент отсутствует значит сказать пользователю прямо: какой шаг
встал, какой командой это чинится, и что конвейер может пройти без этого
шага или не может.

HyperFrames и video-use ставятся один раз на машину, не на каждый проект.

## Шаг 1. Инвентаризация папки проекта

Проверить, что лежит в папке проекта:

| Что ищем | Где смотреть | Даёт вход для |
|---|---|---|
| Видео | файлы `.mp4`, `.mov`, `.mkv` в папке проекта | autocut, word-timing |
| Референс | ссылка, файл, описание в брифе | `decompose-ref` |
| Готовый сценарий | `script.md` в папке проекта | `storyboard` |
| Звук | аудиофайлы, дорожки в исходном видео | word-timing, звук |

## Шаг 2. Формат ролика - спросить, не угадывать

Умолчаний по формату нет, проекты разные. Спросить при каждом запуске:

- соотношение сторон
- длительность
- язык
- нужен ли закадровый голос

## Шаг 3. Список шагов пайплайна

Взять таблицу целиком, отметить каждый шаг «идёт» или «пропущен, потому
что» по фактическому входу из шага 1.

| Шаг | Запускается когда | Чей |
|---|---|---|
| `route` | всегда | наш |
| `decompose-ref` | есть референс | наш |
| `script` | нужен текст или закадровый голос | наш |
| `storyboard` | есть планы, которых ещё нет | наш |
| keyframes | раскадровка утверждена | HyperFrames `/hyperframes-keyframes` + creative-skill |
| генерация шотов | нужны новые шоты | creative-skill |
| `word-timing` | в исходнике есть речь | наш |
| autocut | есть снятый материал с речью | video-use |
| `previz` | нужен точный проход камеры | наш |
| сборка композиции | всегда | HyperFrames |
| моушн и титры | нужны титры и графика | HyperFrames |
| звук | нужен голос или эффекты | HyperFrames audio + MOSS-TTS |
| `loops` | нужен луп | наш |
| рендер | всегда | HyperFrames |
| export-fcp7 | по запросу | наш скрипт |

## Шаг 4. Показать список до запуска

Вывести таблицу шагов пользователю и дождаться подтверждения. Только
после этого передавать управление первому активному шагу.

## Четыре точки остановки

Пайплайн ждёт человека на сценарии, раскадровке, черновике и финале. Плюс
смета creative-skill перед каждой платной генерацией.

| Стоп | Что показывается | Чего ждём |
|---|---|---|
| Сценарий | `script.md` с битами, текстом и таймингом | подтверждения текста и хронометража |
| Раскадровка | холст с артбордами планов | подтверждения планов перед генерацией картинок |
| Черновик | собранная композиция без финального рендера | правок по монтажу, титрам, звуку |
| Финал | готовый рендер | приёмки или списка правок на новый круг |
| Смета creative-skill | стоимость генерации в kie.ai перед запуском | согласия платить именно эту сумму |

## Жёсткие правила

Не запускать платную генерацию без утверждённой раскадровки.
Не пропускать стоп молча - подтверждение спрашивается всегда, даже если
кажется очевидным.
Если шаг пропущен, назвать причину прямо, а не промолчать.
Формат ролика не угадывать по умолчанию, спрашивать при каждом запуске.

## Соседние скиллы

После `route` в работу идут `decompose-ref` (если есть референс), `script`
(если нужен текст) и `storyboard` (если есть планы без картинки). Ссылки
на внешние инструменты (HyperFrames, video-use, creative-skill) даны
в таблице шагов, отдельно их не переизобретать.
