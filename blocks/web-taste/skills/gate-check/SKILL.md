# gate-check

Гейт — это бинарная проверка, без промежуточных оценок: либо да, либо нет.
В отличие от `craft-review` (severity HIGH/MEDIUM/LOW, суждение), здесь
каждый пункт either проходит, либо проваливается. Это второй инструмент на
ту же область, не спор с craft-review — как юнит-тест и ревью кода
дополняют друг друга, не заменяют.

## Порядок

1. Прогнать 58 гейтов из [`slop-test.md`](slop-test.md) — полный список,
   каждый ответ обязан быть «нет».
2. Прогнать три скрипта из `scripts/` на исходниках проекта:
   - `check_contrast.py` — WCAG-контраст пар (одна пара / вся палитра /
     полная матрица ролей)
   - `anti_slop_scan.py` — regex-детектор AI-отпечатков в исходниках
     (типовые градиенты, `transition: all`, dead-ссылки, плейсхолдер-текст)
   - `audit_motion.py` — бюджет motion (transition дольше 300ms, layout-
     свойства в transition, hover без pointer-гейта)
3. Если что-то не прошло — почини, не репортить как норму.

```bash
python3 scripts/check_contrast.py --matrix text=... bg=... primary=... accent=...
python3 scripts/anti_slop_scan.py src/
python3 scripts/audit_motion.py src/
```

Оба скрипта работают по исходникам напрямую (CSS/HTML/JS/JSX/TS/TSX/Vue/
Svelte), не требуют браузера. `check_contrast.py` работает от значений
цвета, не от файлов — передавать роль=hex явно.

## Что не входит

Это бинарный скан, не суждение. Находки уровня «выглядит собранным на
скорую руку» или «иерархия не читается» — не сюда, это `craft-review`.
Гейты 40-41 (контраст) и `check_contrast.py` частично пересекаются с
`web-a11y-code` (когда появится) — не конфликт, разные механики: гейт
проверяет конкретные пары в исходнике здесь и сейчас, `web-a11y-code`
сканирует живой DOM целиком.

## Дополнительно, вне 58 гейтов

Два признака ИИ-эстетики из разведки plannotator/effective-html, которых нет
в оригинальном списке hallmark (не переносить внутрь 58 гейтов, чтобы не
портить дословную нумерацию источника):

- **Кремово-терракотовая или бежево-охристая палитра** как единственная тёплая
  альтернатива фиолетово-синему градиенту из гейта 2, тот же класс клише,
  другой цвет.
- **Эмодзи вместо маркера списка** (🔹, 📌, ✅ перед пунктом вместо обычного
  буллета) - читается как сгенерированный текст даже при нормальной
  типографике вокруг.

## Проверяемый результат (для /loop-build)

Самый checkable блок в кластере: 58 бинарных гейтов + 3 скрипта
(`check_contrast.py`, `anti_slop_scan.py`, `audit_motion.py`). Готово —
когда все три скрипта возвращают чисто и ни один из 58 гейтов не failed.
Реальные команды, не suждение.

## Несколько экранов сразу — распараллелить

Гейт-чек по многим экранам/компонентам за один заход — subagent на
экран, каждый гонит свои 58 гейтов + 3 скрипта независимо (разные файлы,
без общего состояния), сводка в конце одной таблицей.
