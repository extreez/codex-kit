# Упаковка YouTube

## Viewer promise / evidence / stakes / proof

Извлечь из содержания видео перед написанием заголовка/превью:

- **Promise** — что зритель получит, досмотрев (конкретный результат,
  не «интересное видео»).
- **Evidence** — почему автору можно верить в этом обещании (опыт,
  данные, показанный результат).
- **Stakes** — что теряет зритель, если не посмотрит (актуальность,
  срочность, релевантность его ситуации).
- **Proof** — визуальное/текстовое подтверждение прямо в превью
  (цифра, скриншот результата, узнаваемый элемент).

Заголовок и превью не повторяют друг друга дословно — превью
показывает Proof визуально, заголовок формулирует Promise текстом,
вместе они закрывают Stakes.

## Визуальная иерархия превью

Главный элемент (лицо/объект/результат) крупнее подчинённых в
2-3 раза — зритель должен опознать, о чём видео, за долю секунды в
маленьком превью в ленте, не только на полном экране.

## Safe-zone

Проверка, что ключевой текст/элемент превью не попадает в зоны,
перекрываемые интерфейсом YouTube (таймкод видео, значок статуса,
подписи на мобильном) — критичный элемент должен читаться даже
частично перекрытым.

## Анализ видео-выбросов (outlier detection)

Метод поиска паттернов упаковки у конкурентов без прямого копирования:

1. Собрать все видео канала (или набора каналов ниши) за период.
2. Найти **outlier-видео** — просмотры в 2x+ раза выше среднего по
   каналу (не абсолютное число просмотров, а относительное отклонение
   от собственной базы канала — иначе крупный канал будет казаться
   успешным на каждом видео).
3. Извлечь общее в заголовке/превью этих выбросов — какой Promise/
   Proof повторяется, какая визуальная иерархия.
4. **Обязательная проверка перед тем как считать паттерн валидным** —
   не полагаться на разовый выброс:
   - CTR за первые 24-48 часов выше обычного для канала.
   - Durability просмотров за 7 дней (не только первый день).
   - Устойчивость за 28 дней (не быстро затухающий интерес).

Паттерн, не прошедший все три проверки, — вероятно случайность
(попал в тренд по внешней причине), не воспроизводимая формула
упаковки.

## Частые ошибки

- Заголовок и превью говорят об одном и том же дословно — теряется
  дополнительный слой информации, который мог бы усилить клик.
- Паттерн конкурента копируется после одного успешного видео без
  проверки на durability — разовая случайность принимается за
  формулу.
- Ключевой текст превью размещён в зоне, перекрываемой таймкодом на
  мобильном интерфейсе.

## Вопросы для уточнения задачи

1. Нужен заголовок/превью для конкретного видео, или анализ
   конкурентов для выявления паттерна?
2. Если анализ конкурентов — есть доступ к статистике просмотров по
   времени (для проверки durability), или только текущие цифры?
3. Какой Promise у этого видео — что зритель получит, досмотрев?
