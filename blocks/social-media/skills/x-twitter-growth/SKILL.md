# X/Twitter Growth

## Аудит профиля

Проверить перед стратегией роста: bio отвечает на «зачем подписываться»
за 2 секунды чтения, закреплённый твит представляет текущую тему/
экспертизу, шапка профиля не устарела.

## Конкурентный анализ хуков

Собрать топ-выступления 5-10 аккаунтов в нише (по вовлечённости, не
по подписчикам) — извлечь паттерн первой строки, не копировать
дословно. Искать повторяющуюся структуру, не разовую удачную фразу.

## 4 типа постов

| Тип | Когда использовать |
|---|---|
| Тред | Идея требует разворачивания по шагам, каждый твит-звено самостоятельно ценен |
| Атомарный твит | Одна законченная мысль, не нуждается в продолжении |
| Цитата с комментарием | Реакция на чужой контент с добавленной ценностью, не просто согласие |
| Ответ | Engagement под чужим постом — комментарий добавляет мысль, видимую широкой аудитории оригинала |

## Founder-voice длинный пост

Структура: hook → setup (контекст) → problem-solution → визуальная
опора (ASCII-диаграмма или структурированный список) → «неудобная
правда» (контраст с общепринятым мнением ниши) → payoff (вывод/CTA).

Не каждый пост нуждается во всех элементах — структура для случаев,
когда пост претендует на широкий охват (не рядовое обновление).

## Humanizer-чек-лист (AI-паттерны)

Перед публикацией длинного поста — быстрая проверка 24 паттернов,
топ по частоте (полный список — `copywriting/copy-editing/references/
ai-word-list.md`):

- Слова: `delve`, `tapestry`, `leverage`, `synergy`, `paradigm`,
  `ecosystem`, `innovative`, `cutting-edge`.
- Конструкция **«This is not X, it's Y»** — топ-1 признак AI-текста в
  ленте X, использовать редко и только при реально сильном контрасте.
- Идеально симметричные абзацы, голые списки прилагательных без
  цифр и глаголов.

## Таблица весов алгоритма (ориентировочно, меняется)

| Сигнал | Вес |
|---|---|
| Время до первого ответа (первые 30-60 минут) | Высокий |
| Ответы с продолжением диалога (не односложные) | Высокий |
| Репосты с комментарием | Средне-высокий |
| Лайки | Низкий относительно остальных сигналов |
| Внешние ссылки в самом посте | Штраф к охвату (лучше в первом комментарии) |

Веса алгоритма меняются чаще, чем любая другая часть этого скилла —
относиться как к ориентиру, не как к гарантированной формуле, и
пересматривать при заметном падении охвата без изменения качества
контента.

## Частые ошибки

- Ссылка на внешний сайт прямо в теле поста вместо первого комментария
  — снижает охват на большинстве конфигураций алгоритма.
- Тред без самостоятельной ценности каждого звена — читатель, увидевший
  только один твит из середины, не понимает и не получает пользы.
- Founder-voice структура применяется к каждому посту без разбора —
  выглядит шаблонно при частом использовании одной и той же формы.
