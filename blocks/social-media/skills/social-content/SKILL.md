# Контент для соцсетей

## Формулы хуков (первые 1-2 секунды/строки)

| Формула | Структура | Пример угла |
|---|---|---|
| Контраст с ожиданием | «Все говорят X, но на самом деле Y» | Развенчание общего мнения ниши |
| Личный провал/урок | «Я потерял [что-то], пока не понял [урок]» | Уязвимость + практический вывод |
| Цифра-крючок | «[Цифра] [единица] за [время]» | Конкретный измеримый результат |
| Прямой вопрос боли | «Всё ещё делаете [частая ошибка]?» | Узнавание себя в проблеме |
| Список-обещание | «[N] способов [результат]» | Читатель заранее знает объём и формат |

Правило: хук должен быть понятен без контекста остального поста — если
для понимания хука нужно прочитать второй абзац, хук не сработал.

## Репурпозинг длинного контента

Один длинный материал (статья, подкаст, вебинар) → несколько атомов:

1. **Выделить 5-10 самостоятельных идей** — каждая должна работать
   без остального контекста.
2. **Под каждую идею — формат под платформу**: цитата-карточка,
   короткий тред (X), карусель (LinkedIn/Instagram), короткое видео
   (сценарий, не монтаж — см. блок производства видео, когда появится).
3. **Не публиковать все атомы сразу** — распределить на 1-2 недели,
   каждый со своим хуком, не одинаковой подачей.

## Недельный батчинг

Планирование контента блоками, а не по одному посту в моменте:

- Раз в неделю (1-2 часа) — написать черновики постов на неделю
  вперёд по content pillar (`social-media-strategy`).
- Держать буфер на реактивный контент (тренд/новость дня) отдельно от
  запланированного — не весь календарь жёстко фиксирован.
- Ревью раз в месяц — какие форматы/темы реально сработали, обновить
  план на основе этого, не по интуиции.

## Структура short-form видео-сценария

Только сценарий и копия — не монтаж/съёмка (это будущий отдельный
блок производства видео).

**3-second rule**: первые 3 секунды должны содержать хук, не
представление/логотип/раскачку — зритель решает остаться или
проскроллить за это время.

Структура: хук (0-3 сек) → обещание/контекст (3-8 сек) → основной
контент (8 сек - конец минус 5) → чёткий вывод/CTA (последние 5 сек).

Проверка сценария перед съёмкой: если убрать первую фразу — теряет ли
видео смысл сразу? Если нет — первая фраза не хук, переписать.

## Social listening

Мониторинг упоминаний бренда/категории/конкурентов в комментариях и
профильных сообществах — не для прямых продаж, а для сбора языка
аудитории (сверить с `ux-research/customer-research`, режим 2) и
своевременной реакции на негатив до эскалации.

## Частые ошибки

- Хук объясняет контекст вместо того, чтобы зацепить — «Сегодня хочу
  рассказать о...» вместо прямого крючка.
- Репурпозинг публикует все атомы длинного материала в один день —
  выглядит как спам, атомы конкурируют друг с другом за внимание.
- Батчинг без буфера на реактивный контент — план становится жёстким,
  канал не реагирует на реальные события ниши.
