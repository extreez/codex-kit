# dev-onboarding

Отчёт для человека, который открывает проект впервые. Не карта для агента —
той агент строит себе сам через Glob/Grep или через repowise (см. `library/codebase-map`).

## Порядок

### Шаг 1. Проверить, подключён ли repowise

Есть MCP repowise в проекте — бери структуру, граф зависимостей и health-score
оттуда, не пересчитывай руками. Нет — переходи к шагу 2 (ручной проход),
не жди, пока пользователь поставит repowise.

### Шаг 2 (без repowise). Ручной проход

Точка входа (main/index/app), затем от неё по одному уровню импортов вглубь,
не дальше 2-3 уровней — отчёт для введения, не полная карта.

### Шаг 2б. Проект крупный (десятки+ директорий верхнего уровня) — веером

Один последовательный проход по большому проекту — медленно и поверхностно.
**Спроси модель и эффорт** (правило обязательное), затем по одному агенту
на каждую директорию верхнего уровня — Explore-тип, без Edit/Write: что
внутри, за что отвечает, с чем связана снаружи (импорты наружу/внутрь).
Веди список директорий сам (Glob), не отдавай поиск агенту — правило из
`orchestrate`. Собери ответы всех агентов в единый отчёт на шаге 3.

Немного директорий — шаг 2 обычным проходом, агенты здесь не окупятся.

### Шаг 3. Собрать отчёт

- **Что это** — одна-две строки, что делает проект, для кого.
- **Точка входа** — с чего начинается выполнение, файл и строка.
- **Слои** — на какие крупные части поделено и что каждая отвечает (не список
  файлов, а список ответственностей).
- **Куда лезть за типовой задачей** — 3-5 частых запросов («добавить эндпоинт»,
  «поменять валидацию формы») и где в проекте это делается.
- **Что хрупкое** — если repowise дал health-score или мёртвый код, вынести
  сюда: где осторожнее, что явно требует внимания.
- **Как запустить и проверить** — команды запуска и тестов, если раньше не
  находил их сам — см. блок `run`.

### Шаг 4. Не гадать про непрочитанное

Часть проекта не открывалась (слишком большая, недоступна) — прямо написать
в отчёте «не разобрано», не выдумывать по названиям файлов.

## Соседи

Источник графа — `library/codebase-map` (repowise рекомендован). Как
запустить и увидеть проект живьём — блок `run`.
