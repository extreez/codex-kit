---
description: Написать падающие тесты под находки аудита
argument-hint: "[путь к отчёту аудита или id пункта]"
---

Запусти скилл `sec-tests`.

Аргумент `$ARGUMENTS`: путь к отчёту `sec-audit` или конкретный id пункта
(например AC-1). Пусто — возьми свежий отчёт из `docs/security/`.

Обязательно:
1. Спроси модель и эффорт под тесты.
2. Детект тест-раннера проекта. Не тащи новый фреймворк, если есть свой.
3. На каждую находку — тест, который сначала ПАДАЕТ на текущем коде (red).
   Не упал — верни находку на разбор, не оставляй зелёный пустой тест.
4. Отчёт: пункт → red/green/всё ещё red.

Код не чини без отдельной просьбы.
