description: Красная команда по своему приложению (localhost)
argument-hint: "[адрес цели, по умолчанию localhost]"
---

Запусти скилл `sec-attack`.

Аргумент `$ARGUMENTS`: адрес своей цели. Пусто — спроси, обычно localhost с
портом приложения.

Обязательно:
1. Предохранитель: только localhost или явно свой домен. Чужой адрес — стоп.
2. Спроси модель и эффорт под красную команду.
3. Атакуй по находкам аудита через `sec-redteam`, вердикт только с ответом сервера.
4. Отчёт: пробито / держит, и разбор расхождений с аудитом.

Ломать чужое нельзя. Strix — по отдельной просьбе (references/strix.md).
