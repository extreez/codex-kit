# Strix — автономный пентестер

Strix (github.com/usestrix/strix) — агент-пентестер: сам ищет и эксплуатирует в
песочнице, даёт отчёт. Тяжелее ручной красной команды, требует Docker и ключ к
модели. Бери, когда нужен широкий автономный проход, а не точечная проверка.

## Два пути установки

**Через каталог (обёртка с предохранителем).** Готовая обёртка лежит в
`codex-kit/apps/strix/`: проверяет, что цель — свой локальный проект, требует
ключи и Docker, кладёт отчёт в `docs/security/`.

```bash
apps/strix/run.sh <путь-к-своему-проекту>
```

**Без каталога (просто git clone / установщик).** Strix самодостаточен, каталог
ему не нужен:

```bash
git clone https://github.com/usestrix/strix
# или официальный установщик:
curl -sSL https://strix.ai/install | bash
# или PyPI:
pipx install strix-agent
```

`curl | bash` исполняет код из сети — сначала посмотри, что качаешь (DE-2).

## Ключи и запуск

```bash
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="твой-ключ"
strix -n -t ./ --scan-mode quick     # headless, быстрый
strix --target ./app-directory       # интерактивно
```

## Предохранитель остаётся

Сканируй только свой проект. Не натравливай Strix на чужие адреса — это уже атака
на чужое. Обёртка `run.sh` отбивает не-локальные цели, при прямом запуске следи
сам.

## Границы

- Strix не входит в стек `secure` по умолчанию: внешний тяжёлый инструмент,
  включается руками.
- Его отчёт — вход для `sec-tests`: находки закрываются падающими тестами.
- Полная инструкция: `apps/strix/README.md`.
