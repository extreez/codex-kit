---
description: Цикл аудит-фикс-тест до нуля находок
---

Запусти цикл безопасности по скиллу `sec-loop`, механизм 2.

Критерий остановки (проверяемый): ноль CONFIRMED-находок И все sec-тесты зелёные.

Один проход: `/sec-audit` → на каждый CONFIRMED `/sec-tests` (red) → фикс →
`/sec-attack` по localhost → снова аудит. Ноль и зелёные — стоп.

Спроси модель и эффорт под шаги. Фикс прогоняет тесты после каждого изменения,
откат при красных. Файлы без подтверждения не перезаписывай.
