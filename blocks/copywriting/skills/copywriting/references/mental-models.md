# Модели убеждения — справочник

Не чек-лист «примени все сразу» — таблица для подбора одной-двух
моделей, реально подходящих ситуации. Злоупотребление (5+ моделей в
одном тексте) читается как манипуляция и подрывает доверие.

## Ценность и цена

| Модель | Механизм | Применение в тексте |
|---|---|---|
| Anchoring (якорение) | Первое увиденное число задаёт рамку для оценки следующих | Показывать сначала самый дорогой тариф, чтобы средний казался разумным |
| Decoy effect | Третий, заведомо невыгодный вариант, делает целевой вариант очевидным выбором | Тарифная сетка из 3 тиров, где средний специально выигрывает по сравнению с третьим |
| Charm pricing | Цена вида X99 воспринимается ощутимо ниже X00 | Использовать только если это соответствует голосу бренда — премиальные бренды часто избегают |
| Zero-price effect | Бесплатное воспринимается непропорционально ценнее любой низкой цены | «Бесплатный тариф» конвертит сильнее, чем «$1 первый месяц», даже если цифры сопоставимы |
| Framing | Одна и та же цена звучит по-разному в рамке «за день»/«за месяц»/«за год» | «$2 в день» вместо «$730 в год» для дорогих годовых планов |

## Социальное доказательство и авторитет

| Модель | Механизм | Применение в тексте |
|---|---|---|
| Social proof | Люди копируют поведение похожих на себя людей | Отзывы/логотипы клиентов из того же сегмента, что читатель, не любые |
| Authority | Доверие к экспертному/официальному источнику переносится на заявление | Сертификации, упоминания в изданиях, цитаты экспертов — если реальные |
| Bandwagon | «Все уже это делают» подталкивает присоединиться | Счётчики пользователей/установок — только если цифра действительно убедительна |

## Срочность и дефицит

| Модель | Механизм | Применение в тексте |
|---|---|---|
| Scarcity (дефицит) | Ограниченное количество повышает воспринимаемую ценность | Только если дефицит реальный — фальшивые таймеры разрушают доверие при повторном визите |
| Loss aversion | Страх потерять сильнее мотивирует, чем шанс приобрести | «Не теряйте прогресс» сильнее «получите больше», при равной сути |
| FOMO | Страх упустить что-то, что видят/имеют другие | Уместно для разовых событий (запуск, вебинар), не для постоянного продукта |

## Вовлечённость и обязательство

| Модель | Механизм | Применение в тексте |
|---|---|---|
| IKEA-эффект | Вложенный труд повышает субъективную ценность результата | Онбординг с настройкой под себя повышает удержание сильнее готового шаблона |
| Foot-in-the-door | Согласие на маленькую просьбу повышает шанс согласия на большую | Сначала бесплатная регистрация, потом апгрейд — не наоборот |
| Commitment & consistency | Люди стремятся вести себя последовательно с прошлым выбором | Напоминание о цели, которую пользователь сам поставил при регистрации |
| Endowed progress effect | Прогресс-бар, начатый не с нуля («у вас уже 2 из 5 шагов»), мотивирует сильнее | Онбординг-чеклисты с одним предзаполненным шагом |
| Peak-End Rule | Впечатление о процессе определяется пиковым моментом и концовкой, не средним | Сильная финальная секция важнее ровного текста на всём протяжении |

## Классические фреймворки текста

| Фреймворк | Структура |
|---|---|
| AIDA | Attention → Interest → Desire → Action |
| PAS | Problem → Agitate → Solution |
| BAB | Before → After → Bridge |
| Fogg Behavior Model | Поведение = Motivation × Ability × Trigger — все три должны совпасть во времени |

## Границы применения

- Модель подбирается под ситуацию из шага «Human Action Model» скилла
  `copywriting` (дискомфорт/видение/путь), не по принципу «побольше
  психологии в текст».
- Любое заявление, использующее авторитет/социальное доказательство/
  дефицит, обязано быть фактически верным — вымышленный дефицит или
  выдуманная цифра пользователей нарушает `no-ai-slop`-подобные
  принципы честности текста и рушит доверие при проверке.
