# SMS-маркетинг

## Когда SMS уместен

Высокий open rate (обычно **90%+** в течение нескольких минут) делает
SMS сильным каналом для срочных/транзакционных сообщений (напоминание,
подтверждение, ограниченное по времени предложение) — и рискованным
для частого промо-контента, потому что порог раздражения у получателя
ниже, чем у email (отписка от SMS требует меньше усилия и происходит
охотнее).

## Complience (США — TCPA, A2P 10DLC)

**TCPA** (Telephone Consumer Protection Act) — требует явного
письменного согласия (opt-in) перед любой маркетинговой SMS-рассылкой.
Штрафы по искам TCPA — исторически до **сотен долларов за сообщение**,
совокупно иски достигали десятков миллионов долларов при нарушении в
масштабе — это не формальность, а реальный юридический риск при
рассылке без надлежащего opt-in.

**A2P 10DLC** — с 2022 года операторы США требуют регистрацию
приложение-к-человеку рассылок на обычных длинных номерах; без
регистрации сообщения массово блокируются/маркируются как спам
операторами. Регистрация проходит через SMS-провайдера (Twilio и
аналоги), занимает время — планировать заранее, не в последний момент
перед запуском кампании.

**Обязательные элементы каждого сообщения**: чёткий способ отписаться
(STOP), идентификация отправителя в первом сообщении цепочки, никаких
скрытых платных подписок без явного согласия.

## Типы номеров

| Тип | Скорость отправки | Использование |
|---|---|---|
| Long code (обычный номер, A2P 10DLC) | Умеренная | Стандартные маркетинговые/транзакционные рассылки |
| Short code (короткий номер) | Высокая, для больших объёмов | Крупный масштаб, требует отдельной регистрации и выше стоимость |
| Toll-free | Умеренная | Альтернатива long code с собственной регистрацией |

## Экономика по сегментам

Стоимость и лимит символов зависят от кодировки: обычный текст (GSM-7)
даёт больше символов на одно тарифицируемое сообщение, чем текст с
эмодзи/не-латинскими символами (UCS-2, вдвое меньше символов на
сегмент) — сообщение с эмодзи может тарифицироваться как 2-3
сегмента вместо одного при том же визуальном объёме текста.

## Частые ошибки

- Запуск кампании без завершённой регистрации A2P 10DLC — сообщения
  массово блокируются операторами, кампания выглядит проваленной, хотя
  проблема в незавершённой регистрации.
- Отсутствие явного opt-in перед рассылкой — прямой юридический риск
  по TCPA независимо от размера базы.
- Игнорирование разницы кодировки — использование эмодзи в шаблоне
  без понимания, что это удваивает-утраивает стоимость сообщения.
