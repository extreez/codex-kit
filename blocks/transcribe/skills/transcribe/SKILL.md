# transcribe

Своего движка распознавания речи этот блок не несёт — `whisper-windows-mcp`
(eviscerations/whisper-windows-mcp) ставится как есть поверх `whisper.cpp`
(ggml-org, MIT, движок под капотом). Дефолт для Windows-пользователя без
облачных ключей: работает офлайн. Ускорение на видеокарте есть, но только
на дискретной. На встроенной графике процессор с BLAS быстрее в 3-4 раза,
замер в шаге 1.

**Лицензия смешанная**: некоммерческое использование — MIT. Коммерческое
использование требует отдельной лицензии от автора (см.

условия до продакшн-использования, не полагаться на MIT-часть по умолчанию.

## Установка

### Шаг 1. Бинарники whisper.cpp

Архив `whisper-vulkan-win-x64.zip` лежит **не** в релизах
`ggml-org/whisper.cpp`, а в релизах самого `whisper-windows-mcp`, в
версии `v1.4.0`. Официальные сборки whisper.cpp с Vulkan не выпускаются,
это отдельная сборка автора MCP.

```bash
curl -L -o whisper-vulkan.zip https://github.com/eviscerations/whisper-windows-mcp/releases/download/v1.4.0/whisper-vulkan-win-x64.zip
```

Распаковать в `C:\whisper\Release\`. Внутри `whisper-cli.exe`,
`ggml-vulkan.dll` и зависимости.

#### Vulkan не всегда быстрее, проверь своё железо

Замер на Intel Iris Xe и 12-ядерном i5-13500H, модель `base`, 11 секунд
речи:

| Сборка | Первый прогон | Прогретый |
|---|---|---|
| Vulkan на Iris Xe | 3 мин 20 с | 14-18 с |
| BLAS на процессоре | 4.2 с | 4.2 с |

Встроенная графика проиграла процессору в 3-4 раза даже после прогрева.
Первый прогон уходит на компиляцию шейдеров. Расшифровка на выходе
побайтово одинаковая.

Причина: у Iris Xe нет матричных блоков, а память общая с процессором.
На дискретной видеокарте (у автора MCP это AMD Radeon) Vulkan выигрывает
кратно.

**Вывод: со встроенной графикой брать сборку с BLAS.**

```bash
curl -L -o whisper.zip https://github.com/ggml-org/whisper.cpp/releases/download/b4938/whisper-blas-bin-x64.zip
```

| Архив | Откуда | Размер | Кому |
|---|---|---|---|
| `whisper-blas-bin-x64.zip` | ggml-org/whisper.cpp | 20 МБ | встроенная графика, дефолт |
| `whisper-vulkan-win-x64.zip` | eviscerations, релиз v1.4.0 | 17 МБ | дискретная видеокарта |
| `whisper-cublas-12.4.0-bin-x64.zip` | ggml-org/whisper.cpp | 640 МБ | только NVIDIA |

MCP-сервер работает с обеими сборками: он смотрит на
`WHISPER_CLI_PATH`, а не на то, чем считает бинарник.

Сборка из исходников это вариант для нестандартного билда. Требует CMake
и Visual Studio Build Tools 2022 или новее.

### Шаг 2. Модель

Через сам MCP после подключения: `download_model large-v3-turbo` (GPU,
англ./мультиязычный) или `medium.en-q5_0` (CPU, английский, 514 МБ) — выбор
модели зависит от того, есть ли GPU и нужен ли не-английский язык.

### Шаг 3. FFmpeg (для видео и форматов кроме mp3/wav)

```bash
winget install ffmpeg
```

### Шаг 4. Подключение MCP

```bash
claude mcp add whisper --env WHISPER_CLI_PATH=C:\whisper\Release\whisper-cli.exe --env WHISPER_MODEL=C:\whisper\models\ggml-large-v3-turbo.bin -- npx -y whisper-windows-mcp
```

Пути — двойные обратные слэши, если редактируешь конфиг вручную вместо
команды выше. После первого подключения свериться командой `check_config`
(сам MCP-инструмент) — доступны ли бинарник и модель.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `transcribe_audio` | Расшифровка файла (язык, формат вывода, GPU on/off) |
| `start_batch` | Очередь на папку целиком, короткие файлы первыми |
| `generate_subtitles` | SRT/VTT, опционально с переводом на английский |
| `analyze_media` | Длительность, кодек, оценка времени обработки до запуска |
| `check_system` | Определение GPU, рекомендация модели под железо |
| `switch_model` | Смена активной модели в сессии без переподключения |
| `whisper_server` | Персистентный процесс — ускоряет повторные вызовы подряд |

## Пересечение с `claude-video`

Блок `claude-video` (если установлен) уже включает Whisper-транскрипцию как
часть скачивания и разбора видео. Нужна только расшифровка аудио/видео без
остального конвейера (скачивание, кадры) — `transcribe` компактнее и не тянет
лишнее. Нужен полный конвейер видео — `claude-video`. Не конфликт, разная
область: этот блок только распознавание речи.
