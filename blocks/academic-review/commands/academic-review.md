---
description: Запустить ревью научного текста
argument-hint: "[режим: self-review|panel|rebuttal|re-review, по умолчанию self-review]"
---

Запусти ревью по скиллу `academic-review`.

Аргумент `$ARGUMENTS`: режим, если пользователь его уже знает. Пусто -
определи по формулировке запроса (свой черновик перед подачей - self-review;
собрать панель - panel; получено чужое ревью, нужен ответ - rebuttal; правки
внесены, проверить закрытие - re-review).

Обязательно по порядку:
1. Спроси модель и эффорт под `paper-reviewer` (и под self-review, если
   субагент оправдан объёмом текста) - правило, не пропускай.
2. Self-review: аудит структуры, логики аргумента, фигур (читай изображения
   напрямую), соответствия формату издания.
3. Panel: Sprint Contract до чтения полного текста -> панель `paper-reviewer`
   с углом-параметром (journal-fit, 2 дисциплинарных, devil's-advocate порог
   ≥4) -> расхождения через `debate`, не голосованием.
4. Rebuttal: по каждому пункту чужого ревью - согласен/не согласен + что
   изменено, evidence-based.
5. Re-review: traceability-матрица замечание -> изменение -> подтверждено ли,
   перечитать место правки, не верить слову "исправлено".

Непроверенные фактические утверждения по ходу ревью - направить в
`fact-check`, не проверять самостоятельно.
