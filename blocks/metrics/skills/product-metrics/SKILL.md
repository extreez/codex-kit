# Product Metrics

Три скилла phuryn/pm-skills про то, какие метрики выбирать и как их
организовать — стратегический слой, а не техническая реализация трекинга.

| Запрос пользователя | Файл | Что делает |
|---|---|---|
| «какую метрику выбрать North Star», «метрики созвездие», «что измерять» | `north-star-metric.md` | классифицирует игру бизнеса (Attention/Transaction/Productivity), предлагает NSM по 7 критериям + 3-5 input-метрик |
| «собери дашборд метрик», «определи KPI», «план мониторинга данных» | `metrics-dashboard.md` | слои North Star → Input → Health → Business, таблица метрика/источник/визуализация/порог алерта, каденция ревью (daily/weekly/monthly/quarterly) |
| «проанализируй retention по когортам», «adoption фичи по когортам», «почему отток растёт» | `cohort-analysis.md` | retention-кривые, heatmap по когортам, feature adoption, план последующего качественного исследования |

## Соотношение между скиллами

`north-star-metric.md` выбирает один customer-centric показатель.
`metrics-dashboard.md` строит вокруг него полную иерархию метрик и
операционку (кто на что смотрит и как часто). `cohort-analysis.md` —
инструмент разбора конкретных данных retention/adoption, применим
независимо от того, выбран ли уже North Star.

Обычный порядок: `north-star-metric.md` → `metrics-dashboard.md`
(NSM становится верхним слоем дашборда) → `cohort-analysis.md` по мере
накопления данных.

Открой нужный файл целиком и следуй его инструкциям — там же промпты,
таблицы критериев и ссылки на дальнейшее чтение, сохранённые дословно
из оригинала.
