# Переменные шрифты и OpenType

Что умеет файл шрифта помимо отрисовки букв, и как дотянуться до этих
возможностей из CSS.

## Статический vs переменный

- **Статический шрифт:** одна насыщенность и один стиль на файл. Regular,
  medium и bold — три файла.
- **Переменный шрифт:** весь диапазон в одном файле. Работает любое
  значение внутри, например `font-weight: 589`.

Переменный шрифт не автоматически лучше. На одной-двух насыщенностях
статичные файлы могут быть меньше. На нескольких насыщенностях, оптических
размерах или кастомных осях переменный обычно выигрывает.

## Грузи задуманные насыщенности и стили

Если используется насыщенность или стиль, которых нет в активном
семействе, браузер может их синтезировать — грузить нужно те начертания,
что использует дизайн. `none` отключает синтез насыщенности, стиля,
small-caps, superscript и subscript разом и может стереть различия, когда
реального начертания нет. Проверять весь fallback-стек и каждое состояние
акцента перед тем, как его ставить.

```css
.brand-wordmark {
  /* Безопасно только после проверки этой изолированной обработки */
  font-synthesis: none;
}
```

Для основного и интерфейсного текста держать синтез включённым, если
только проверенная настройка шрифта не даёт каждую нужную форму. Если не
нужен только один режим — использовать конкретный longhand
(`font-synthesis-weight`, `font-synthesis-style` и связанные), не общий
shorthand.

## Оси

Контролы переменного шрифта, каждая с четырёхбуквенным тегом. Шрифт
поддерживает только те оси, что включил его дизайнер.

| Ось | Тег | Управляет |
| --- | --- | --- |
| Насыщенность | `wght` | Толщина штриха (как `font-weight`) |
| Оптический размер | `opsz` | Детали и отступы, подстроенные под размер показа |
| Ширина | `wdth` | Ширина глифа |
| Наклон | `slnt` | Угол наклона |
| Кастомная | напр. `GRAD` (Roboto Flex) | Что бы ни построил дизайнер |

Переменный файл Inter раскрывает только `wght` и `opsz`.

Оптические размеры существовали до переменных шрифтов, многие семейства
до сих пор поставляют их отдельными файлами. Heldane Text прочнее и
просторнее для читательских размеров, Heldane Display тоньше для
крупных.

## Свойства вместо тегов осей

Когда свойство существует — использовать его. `font-weight` продолжает
работать при рендере не-переменного фолбэка, `font-variation-settings`
молча ничего не делает. Сырые теги оставлять для кастомных осей без
своего свойства:

```css
/* Хорошо: распространённые оси через свойства */
.heading {
  font-weight: 650;
  font-optical-sizing: auto;
}

/* Хорошо: кастомная ось без своего свойства */
.heading-grade {
  font-variation-settings: "GRAD" 80;
}

/* Плохо: насыщенность через сырой тег ломается на fallback-шрифтах */
.heading {
  font-variation-settings: "wght" 650;
}
```

## OpenType-фичи

OpenType — стандарт почти за каждым современным шрифтом. Фичи — доп.
встроенные опции, в отличие от осей работают одинаково на статичных и
переменных шрифтах. Шрифт поставляет только те фичи, что включил
дизайнер.

| Тег | Фича |
| --- | --- |
| `tnum` | Табличные цифры: каждая одной ширины |
| `zero` | Перечёркнутый ноль: `0` отличим от `O` |
| `liga` | Лигатуры: соединяет пары вроде "fi" в одну форму |
| `ss01`-`ss20` | Стилистические наборы (нумерованные слоты) |
| `cv01`-`cv99` | Варианты символов (нумерованные слоты) |

То же правило, что с осями. Предпочитать `font-variant-*` свойства,
оставлять `font-feature-settings` для тегов без своего свойства:

```css
/* Хорошо: распространённые фичи через свойства */
.price {
  font-variant-numeric: tabular-nums;
}

/* Хорошо: перечёркнутый ноль тоже через свойство */
.id {
  font-variant-numeric: slashed-zero;
}

/* Хорошо: нишевая фича без своего свойства */
.logo {
  font-feature-settings: "ss01" 1;
}
```

Табличные цифры важны для меняющихся значений. Без них у каждой цифры своя
ширина, layout сдвигается при обновлении.

## Капитель, надстрочные, подстрочные

- **Капитель:** прописные буквы, отрисованные меньшим размером. Включать
  настоящую капитель через `font-variant-caps`.
- **Надстрочные** сидят над обычной строкой, как 2 в x², **подстрочные** —
  под ней, как в H₂O. Включать правильные глифы через
  `font-variant-position`.

Обе требуют, чтобы шрифт включал нужные глифы.

## Стилистические наборы и варианты символов

`ss01` = стилистический набор, слот 01. `cv11` = вариант символа, слот 11.
Что делает каждый слот, отличается от шрифта к шрифту, поэтому они
нумерованы, не названы. Смотреть документацию шрифта. В Inter `ss01`
переключает на открытые цифры, `cv11` меняет однострочную `a`.
