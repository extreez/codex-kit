# Выбор шрифтов

Выбор гарнитуры, нужного формата файла и почему шрифты выглядят так, как
выглядят.

## Выбор гарнитуры

Семейство шрифта задаёт тон раньше, чем конкретный шрифт.

| Категория | Черты | Использовать для |
| --- | --- | --- |
| Serif (с засечками) | Мелкие штрихи на концах букв ведут взгляд вдоль строки | Длинные тексты, editorial-чтение |
| Sans-serif (без засечек) | Чистые, ровные формы, чёткие на мелких размерах | Дефолт для большинства интерфейсов (Helvetica, Inter, Geist) |
| Monospace (моноширинный) | Каждый глиф одной ширины, колонки выравниваются | Код, таблицы, табличные данные |
| Display (дисплейный) | Нарисован под крупные заголовки | Маркетинговые заголовки, hero-текст |
| Script (рукописный) | Имитирует почерк | Редкие, декоративные моменты |

CSS даёт ключевые слова `cursive` и `fantasy` для двух последних
категорий.

"Display" в имени шрифта не делает его дисплейным. SF Pro и Heldane
поставляют вариант `Display` для крупных размеров и `Text` для мелких.
Использовать вариант, соответствующий размеру, который задаёшь.

### Правила

- Меньше шрифтов обычно лучше. Редко больше трёх. Маркетинговые страницы
  могут быть выразительнее приложений.
- То же с размерами и насыщенностями. Они определяют иерархию,
  чрезмерное использование быстро вредит читаемости.
- Сочетать контрастно, не похоже. Serif-заголовок над sans-телом читается
  как осознанное разделение дисплея и чтения; два почти одинаковых sans —
  как ошибка.
- Тонкие насыщенности только дисплейные. Ниже `18px` — насыщенность
  `400`+, потому что штрихи Ultralight, Thin и Light (`100`-`300`)
  исчезают на текстовых размерах и на низком DPI. Резервировать их для
  дисплейного текста от `28px`+, и даже там проверять, держатся ли они на
  фоне.

## Область применения семейства шрифтов

Применение или ревью типографики никогда не требует нового шрифта.
Использовать систему шрифтов продукта, если задача не просит смену
шрифта, и никогда не вводить платную или проприетарную гарнитуру ради
галочки в чек-листе. Детали рендера — сглаживание, перенос, табличные
цифры — не переопределяют семейство шрифта проекта.

Когда смена шрифта запрошена — два пути. Системный стек даёт нативное
ощущение macOS и iOS. Коммерческая гарнитура вроде Helvetica Now — брендовое
решение, всё равно нуждается в fallback-стеке.

```css
/* Нативное ощущение macOS/iOS */
html {
  font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}

/* Коммерческая брендовая гарнитура с безопасными фолбэками */
html {
  font-family: "Helvetica Now", "Helvetica Neue", Arial, sans-serif;
}
```

## Форматы

| Формат | Заметки |
| --- | --- |
| `.woff2` | Brotli-сжатие, широкая поддержка. Использовать в вебе. |
| `.woff` | Старое сжатие. Только фолбэк для очень старых браузеров. |
| `.ttf` / `.otf` | Сырые форматы, без веб-сжатия, крупнее файлы. Только десктоп, если нет альтернативы. |

## Анатомия гарнитуры

| Термин | Значение |
| --- | --- |
| x-height | Высота строчной `x` |
| Cap height | Высота прописных букв |
| Baseline | Невидимая линия, на которой стоят буквы |
| Ascender | Часть буквы, поднимающаяся выше x-height |
| Descender | Часть, опускающаяся ниже baseline |

Эти измерения — причина, почему два шрифта на одном `font-size`
выглядят разного размера. Крупный x-height выглядит крупнее.
