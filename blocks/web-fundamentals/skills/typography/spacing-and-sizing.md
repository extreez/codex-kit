# Отступы и размеры

Разумная шкала и комфортный отступ делают для типографики больше, чем
любой эффект.

## Единицы

| Единица | Поведение |
| --- | --- |
| `px` | Фиксированная |
| `em` | Масштабируется с текущим размером шрифта |
| `rem` | Масштабируется с корневым размером шрифта |
| `%` на `font-size` | Относительно размера шрифта родителя, ведёт себя как `em` |

## Типографическая шкала

Небольшой набор размеров, используемый по всему продукту, от которого
отклоняются минимально. Захардкоженные размеры без системы ломаются на
масштабе.

```css
:root {
  --text-sm: 0.875rem;
  --text-base: 1rem;
  --text-lg: 1.125rem;
  --text-xl: 1.5rem;
  --text-2xl: 2rem;
}
```

Выбрать существующую шкалу или определить свою. Шкала Tailwind (`text-xs`
до `text-9xl`, каждый класс сочетает размер с подходящим line-height) —
надёжный готовый вариант.

В одиночку дефолтные имена работают при ясных правилах, где какой размер
использовать. В команде — называть размеры семантически. `text-sm`
сообщает размер, но не назначение, `text-body-sm` несёт оба.

Ролевая шкала сочетает каждый размер с его line-height и насыщенностью,
превращая роль в одно решение вместо трёх. Отправная точка для
интерфейса продукта:

| Роль | Размер | Line-height | Насыщенность |
| --- | --- | --- | --- |
| Display | `2.25rem` (36px) | `1.1` | `600` |
| Title | `1.5rem` (24px) | `1.2` | `600` |
| Heading | `1.125rem` (18px) | `1.3` | `600` |
| Body | `1rem` (16px) | `1.5` | `400` |
| Caption | `0.8125rem` (13px) | `1.4` | `400` |

Акцент внутри роли — на один шаг насыщенности выше (`400` → `500`), не
смена размера.

## Иерархия заголовков

Присвоить каждому уровню заголовка убывающий шаг шкалы, чтобы иерархия
шла от шкалы, а не от произвольных размеров:

```css
h1 { font-size: var(--text-2xl); }
h2 { font-size: var(--text-xl); }
h3 { font-size: var(--text-lg); }
```

В Tailwind то же сопоставление — utility-классы на уровень (`text-2xl`,
`text-xl`, `text-lg`), централизованные в компоненте или `@layer base`, не
повторённые инлайн.

При ревью сравнивать вычисленный размер заголовков внутри каждой
семантической секции. Дочерний элемент, рендерящийся заметнее родителя,
ломает иерархию. Глубокие уровни могут делить размер, где шкала кончает
удобные шаги, пока насыщенность или letter-spacing держат их отличимыми.
Заголовок никогда не меньше основного текста, если это намеренно не
overline-лейбл.

Семантика заголовка и качество outline — забота `web-a11y-code`. Выбирать
элемент из структуры документа, затем этим скиллом делать структуру
визуально легитимной. Никогда не выбирать элемент заголовка за его
браузерный размер по умолчанию.

## Кернинг и letter-spacing

- **Кернинг** подстраивает конкретные пары букв, например `AV` или `Ye`.
  Встроен в шрифт и применяется автоматически. Отключать только осознанно,
  `font-kerning: none`.
- **`letter-spacing`** добавляет одинаковый отступ между каждым символом.

```css
/* Хорошо */
.display-heading {
  letter-spacing: -0.02em;
}

.uppercase-label {
  text-transform: uppercase;
  letter-spacing: 0.05em;
}
```

## Line-height

| Текст | Значение |
| --- | --- |
| Заголовки | ~`1.1` |
| Основной текст | `1.5`-`1.6` |

Tailwind `leading-snug`, `leading-normal` и `leading-relaxed` — разумные
дефолты, редко нуждающиеся в переопределении. Плотно сжатый абзац читать
труднее, чем вписать более высокую строку.

```css
/* Плохо: описание карточки на line-height заголовка */
.card-description { line-height: 1.1; }

/* Хорошо: переносится на 3 строки, читается как основной текст */
.card-description { line-height: 1.4; }
```

## Обрезка текста через text-box

Шрифты резервируют пространство над и под буквами, поэтому текст сидит
чуть ниже, чем нужно, в кнопках и бейджах. `text-box` обрезает это. Две
части: какие края обрезать (`trim-both`, `trim-start`, `trim-end`) и где:

| Ключевое слово | Обрезает по |
| --- | --- |
| `cap` | Высоте прописных (верх) |
| `alphabetic` | Базовой линии (низ) |
| `text` | Собственному текстовому краю шрифта, оставляя место под descender'ы |

```css
/* обрезать сверху и снизу */
.badge {
  text-box: trim-both cap alphabetic;
}

/* обрезать только сверху */
.heading {
  text-box: trim-start cap;
}

/* обрезать только снизу */
.label {
  text-box: trim-end alphabetic;
}
```

Поддержка в Chromium (133+) и Safari (18.2+), пока не Firefox. Считать
progressive enhancement — неподдерживающие браузеры сохраняют дефолтный
leading.
