# Панель экспертной оценки

## Механизм

1. **Собрать панель** из 5-10 экспертных персон, релевантных типу
   контента (например для блог-статьи: SEO-редактор, целевой читатель-
   персона, скептичный конкурент, эксперт по теме статьи, редактор
   голоса бренда). Для соцсетей — заменить на профильные роли (алгоритм
   платформы, типичный подписчик, формат-эксперт).
2. **Обязательные судьи**, если применимо к типу контента:
   - **AI Writing Detector** — не отдельная персона, а обязательная
     проверка по `copywriting/copy-editing/references/ai-word-list.md`,
     вес выше среднего (1.5x) относительно остальных судей — AI-штампы
     подрывают доверие сильнее, чем отдельная слабая формулировка.
   - **Brand Voice Match** — сверка с секцией 9 контекста продукт-
     маркетинга или блоком `brand-voice`, если прогонялся.
3. **Каждый судья ставит балл 0-100** с кратким обоснованием (не
   просто число — иначе непонятно, что чинить).
4. **Порог прохождения**: 80-90 в зависимости от критичности контента
   (90 — флагманский/долгоживущий материал, 80 — рядовая публикация).
5. **До 3 раундов правки.** Каждый раунд бьёт по трём самым слабым
   местам (не переписывает всё) — судья с самым низким баллом и
   конкретной причиной определяет, что чинить в первую очередь.
6. **Если после 3 раундов порог не достигнут** — не зацикливаться,
   поднять вопрос человеку: возможно проблема не в тексте, а в
   исходном брифе/идее.

## Хранение паттернов отказа

Если пользователь отклоняет правку панели («не надо, оставь как
есть») — фиксировать это как новое правило снижения строгости для
будущих прогонов того же типа контента, не переспрашивать то же самое
каждый раз заново.

## Когда НЕ применять

- Короткий текст с низкой ставкой (внутренняя заметка, черновик для
  обсуждения) — панель избыточна, тратит больше времени, чем стоит
  сам текст.
- Когда автор явно просит не редактировать голос («это личное мнение,
  не сглаживай») — панель здесь неуместна, это про фактическую
  корректность и структуру, не про тон.

## Формат вывода

```markdown
## Экспертная панель — раунд [N]

| Судья | Балл | Главное замечание |
|---|---|---|
| [роль] | [0-100] | [конкретика, не общие слова] |

**Средний балл**: [X] / порог [Y]
**Топ-3 слабых места для правки**: [список]
**Решение**: [ship / ещё раунд / эскалация человеку]
```
