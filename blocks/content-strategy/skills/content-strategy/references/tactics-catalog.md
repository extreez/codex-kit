# Каталог тактик — чек-лист по категориям

Не применять все сразу — выбрать 3-5 тактик, релевантных стадии и
ресурсу продукта (секция 13 контекста продукт-маркетинга — реальные
каналы, не желаемые).

## Контент

- Столповые статьи с кластером подтем (см. `content-strategy`)
- Оригинальное исследование/опрос своей аудитории с публикацией данных
- Roundup-статья мнений экспертов ниши (co-marketing потенциал)
- Глоссарий терминов категории (Searchable, долгий хвост)
- Шаблоны/чек-листы для скачивания (двойная роль — контент + lead
  magnet, см. `retention-growth`)

## Конкуренты

- Сравнительные страницы "X vs Y" (см. `positioning/positioning-gtm`
  за battlecard-данными)
- Мониторинг изменений в продукте/цене конкурента, разбор публично
- Content gap audit — темы, которые конкурент не закрыл

## Инструменты

- Бесплатный калькулятор/генератор как lead-magnet (см.
  `retention-growth`)
- Публичный бенчмарк-инструмент категории (собственный рейтинг/индекс)

## Платный трафик

- Ретаргетинг посетителей блога на продуктовую страницу
- Тестирование creative-first подхода перед масштабированием бюджета
  (см. `paid-ads`)

## Соцсети

- Репурпозинг длинного контента в атомарные посты (см. `social-media`)
- Комментирование в профильных сообществах без прямой рекламы
- Серия из построенного в реальном времени контента ("building in
  public")

## Email

- Нёрчер-серия на основе топ-контента блога (см. `email-outbound`)
- Персонализированный дайджест по интересам подписчика

## Партнёрства

- Совместный вебинар/гайд с комплементарным (не конкурирующим)
  продуктом (см. `pr-launch/co-marketing`)
- Взаимные упоминания в контенте с партнёром той же аудитории

## События

- Спонсорство узкой профильной конференции вместо широкой (см.
  `pr-launch`)
- Собственный небольшой митап/AMA

## PR

- Питч журналисту под угол "Founder story" или "David vs Goliath" (см.
  `pr-launch`)
- Реактивный newsjacking на отраслевую новость

## Запуски

- Waitlist с реферальным механизмом до публичного запуска
- Поэтапный rollout (alpha→beta→full) с контентом на каждом этапе

## Product-led

- In-app подсказки, ведущие на образовательный контент
- Публичный roadmap с возможностью голосования

## Форматы контента

- Интерактивный калькулятор внутри статьи вместо статичных цифр
- Видео-версия текстового гайда (репурпозинг, не отдельное
  производство с нуля)

## Нестандартные ходы

- Открытый отчёт о собственных метриках/ошибках ("building in public"
  на уровне цифр, не только процесса)
- Юмористический/провокационный формат для узкой темы категории

## Платформы

- Нативный формат под конкретную площадку вместо кросс-постинга
  одного текста везде (см. `social-media` за платформенными лимитами)

## Международное

- Локализация топ-контента на язык растущего рынка, не машинный
  перевод без адаптации культурного контекста

## Dev-ориентированные (если продукт технический)

- Open-source утилита как маркетинговый актив
- Технический deep-dive для инженерной аудитории с честными
  ограничениями подхода

## Аудитория

- Сегментация контентного плана по стадии воронки (TOFU/MOFU/BOFU) —
  не один план на всех
