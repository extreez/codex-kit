# Самопроверка перед выдачей

> Идея бинарной проверки перед рендером взята из cathrynlavery/diagram-design
> (`scripts/self_check.py`) и Archify-Labs/archify (`validate`/`deliver`),
> сама проверка написана заново как ручной чек-лист: у нас нет их скриптов,
> есть только дисциплина "не показывать результат без прохода списка".

Каждый пункт либо да, либо нет. Не прошло - почистить и прогнать список
заново, не описывать проваленный пункт как приемлемый компромисс.

## Структура

- [ ] Список узлов/связей из шага 3 SKILL.md существует и совпадает с тем,
      что реально нарисовано (ничего не добавлено на глаз при рисовании).
- [ ] Не больше 9 первичных узлов на обзорной диаграмме, не больше 5
      lifelines на sequence.
- [ ] Ровно один узел/группа помечены как `focal` (роль "здесь главное").
- [ ] Каждая связь подписана смыслом (действие/условие), не голая стрелка,
      если смысл не полностью и однозначно читается из подписей узлов.

## Разметка

- [ ] Каждая координата, размер, отступ кратны 4px.
- [ ] Все коннекторы горизонталь/вертикаль со скруглением, диагональных линий
      нет.
- [ ] Зазор между стрелкой и подписью 6-10px, подпись не наезжает на линию и
      не наезжает на соседний узел.
- [ ] Ни одна связь не пересекает узел, к которому не имеет отношения.

## Цвет и контраст

- [ ] Пара `ink`/`paper` проходит WCAG AA (посчитано, не на глаз).
- [ ] Ровно один акцентный цвет на всю диаграмму.
- [ ] Различие между ролями узлов не держится только на цвете - форма или
      стиль обводки (сплошная/пунктир) тоже отличаются, чтобы не потерять
      смысл для читателя с дальтонизмом.

## Тема и формат

- [ ] Светлая и тёмная тема заданы через порядок токенов из
      `artifact-design` (`:root` → media query → `[data-theme]`), не
      захардкожены под одну тему.
- [ ] Файл открывается и читается без внешних скриптов (кроме шрифтов через
      `<link>`, если тема проекта их уже требует).
- [ ] На заявленных размерах экрана нет горизонтального скролла и обрезанного
      контента.

## Смысл, не только форма

- [ ] Диаграмму можно молча заменить списком без потери смысла - если да,
      значит диаграмма была не нужна, это тоже валидный вывод самопроверки.
- [ ] Использован семантический паттерн из `semantic-patterns.md`, если хоть
      один подошёл, а не собрано вручную то, что уже описано готовым
      паттерном.
