# dembrandt-color

Ставится как есть через npm, апстрим не копируется в этот блок. Правки —
только через апстрим-репозиторий (`dembrandt/dembrandt`).

`dembrandt` умеет извлекать весь дизайн-язык сайта (типографику, spacing,
тени, motion, компоненты) — этот блок использует только цветовую часть,
остальное принадлежит `design-system-extract` (собирается отдельно, не
дублировать здесь).

## Установка

```bash
npm install -g dembrandt
dembrandt install-browser   # разово, тянет Chromium под playwright-core
```

Без `install-browser` любая команда падает с `browser engine not available`
— это не опция, дембrandt рендерит страницу настоящим браузером, а не
парсит статический HTML. Без установки можно и через `npx dembrandt
<url>`, тогда `npx dembrandt install-browser` тоже разово.

**Только CLI, MCP не подключать.** У dembrandt есть официальный MCP-сервер
(`claude mcp add --transport stdio dembrandt -- npx -y --package dembrandt
dembrandt-mcp`) — этот блок его сознательно не использует, вызов должен
быть явной командой в терминале, не фоновым инструментом агента.

## Команды под цвет

```bash
dembrandt example.com                  # цвета в терминал: семантика, палитра, CSS-переменные, градиенты
dembrandt example.com --wcag           # + WCAG 2.1 контраст по реальным DOM-парам, оценки AA/AAA
dembrandt example.com --tailwind       # Tailwind v4 @theme CSS с наблюдаемыми значениями
dembrandt example.com --dtcg           # W3C Design Tokens (для Style Dictionary/Tokens Studio)
dembrandt example.com --save-output    # сохранить JSON в output/example.com/TIMESTAMP.json
```

`--crawl N` — обойти N страниц и слить в один результат, точнее одной
страницы за счёт кросс-страничной уверенности. `--slow` — утроить таймауты
на тяжёлых от JS сайтах. `--mobile`/`--dark-mode` — извлечь под конкретный
viewport/тему. Полный список флагов — `docs/usage.md` в апстриме.

## Соседние блоки

`oklch-skill` (этот же блок) обрабатывает то, что извлечено: перевести
нотацию, посчитать недостающие шаги рампы. `better-colors` (этот же блок)
задаёт, во что должна сложиться извлечённая палитра — рампы по ролям, не
голый список hex-значений. `design-system-extract` использует тот же CLI,
но для полного дизайн-языка сайта, не только цвета.

## Проверяемый результат (для /loop-build)

CLI-обёртка — готово, когда команда завершается без ошибки и выходной
файл с извлечёнными рампами не пуст. Реальный exit-код, не suждение.

## Несколько сайтов сразу — распараллелить

Извлекаешь палитры с нескольких сайтов для сравнения — subagent на
сайт, каждый в свой выходной файл (не писать в один — коллизия имён).
