# oklch-skill

Ставится как есть через `npx skills add`, апстрим не копируется в этот
блок. Правки — только через апстрим-репозиторий.

## Установка

```bash
npx skills add jakubkrehel/oklch-skill
```

Алиас можно сменить при установке (`-s <имя>`), сам скилл трогать нельзя.

## Что внутри

Инструмент для работы с OKLCH: конвертация между hex/rgb/hsl/oklch,
генерация палитр, gamut-клэмпинг (когда цвет не влезает в sRGB/P3),
резервные значения для старых браузеров. Проверка по WCAG-порогам
контраста в зону этого скилла не входит — это `web-a11y-code`.

## Соседние блоки

`better-colors` (этот же блок, `web-color`) задаёт принципы — какая рампа
правильная, как называть токены, когда переходить на OKLCH. `oklch-skill`
делает саму арифметику по этим принципам: посчитать конкретное значение,
проверить конкретную пару. Разные роли, ставить оба.

`dembrandt-color` (этот же блок) извлекает существующую палитру с живого
сайта — `oklch-skill` пригождается после, чтобы обработать то, что
извлечено (перевести нотацию, посчитать недостающие шаги рампы).

## Проверяемый результат (для /loop-build)

Конвертация детерминирована — готово, когда пересчитанные OKLCH-значения
проходят WCAG-порог через тот же `check_contrast.py`. Реальная команда.

## Несколько наборов значений сразу — распараллелить

Конвертируешь/дозаполняешь рампу сразу для нескольких палитр — subagent
на палитру, независимо, конвертация не имеет общего состояния.
