# PR (earned media)

## Четыре режима

| Режим | Что это | Когда использовать |
|---|---|---|
| **Reactive newsjacking** | Быстрая реакция/комментарий на отраслевую новость дня | Есть свежая новость, где экспертиза продукта релевантна — окно узкое (часы, не дни) |
| **Proactive pitching** | Инициативный питч конкретному журналисту под конкретную историю | Есть готовая история (запуск, данные, кейс), нужен целевой охват через конкретное издание |
| **Inbound (HARO/Qwoted и аналоги)** | Отвечать на запросы журналистов, ищущих экспертный комментарий | Постоянный низкозатратный канал, не разовая кампания — требует регулярного мониторинга запросов |
| **Owned press-page** | Собственная страница для прессы (факты о компании, контакты, медиа-кит) | Базовая гигиена — должна существовать независимо от активности в других режимах, журналист может прийти сам |

## Три угла истории

**Founding Story** — почему основатель начал делать именно это; работает,
если история конкретна и проверяема, не шаблонна («увидел проблему на
собственном опыте»).

**David vs Goliath** — маленький игрок бросает вызов устоявшемуся
рынку/крупному игроку; работает, если разрыв реален и подтверждаем,
не выдуман для драмы.

**Have an Enemy** — история строится вокруг того, с чем борется
продукт. **Правило: враг — сломанная система/устаревший подход/
статус-кво, никогда не конкретный конкурент.** Подача конкурента как
врага юридически рискованна (диффамация) и репутационно токсична
(выглядит мелочно, не уверенно).

## Формат питча журналисту

Короткий (3-5 предложений), с готовым углом (не «у нас классный
продукт, напишите про нас»), с конкретными данными/доступностью для
интервью, без вложений в первом письме — журналисты получают десятки
питчей в день, длинный формат снижает шанс прочтения до конца.

---

## Частые ошибки

- Подача конкурента как врага вместо системы/статус-кво.
- Reactive newsjacking с опозданием (через 2-3 дня после новости) —
  окно релевантности уже закрыто.
- Питч без конкретного угла — просто анонс продукта без истории,
  которую можно написать.
