# Инфлюенсер-маркетинг

## Спектр вовлечённости

| Формат | Обязательства | Стоимость |
|---|---|---|
| Разовый платный пост | Один пост, чёткое ТЗ | Низкая-средняя |
| Серия постов | Несколько публикаций за период | Средняя |
| Продукт за отзыв (gifting) | Без денежной оплаты, только продукт | Низкая, но менее предсказуемый результат/тон |
| Долгосрочное партнёрство | Регулярные интеграции, совместный контент | Высокая |
| Амбассадорская программа | Долгосрочная идентификация с брендом, часто с реферальным элементом (см. `retention-growth/referrals`) | Высокая, но лучшая цена за охват на дистанции |

Выбор формата зависит от того, разовая ли это кампания (запуск
продукта) или системный канал (амбассадоры дешевле на длинной
дистанции, но требуют инвестиции в отношения).

## FTC-комплаенс (США)

**Раскрытие рекламы обязательно** при любых материальных отношениях
(оплата, бесплатный продукт, комиссия) между брендом и креатором —
явная пометка `#ad`/`#sponsored` в самом посте, не только в описании
профиля и не спрятанная среди других хэштегов.

**Отвечает не только креатор, но и бренд** — FTC может привлечь к
ответственности рекламодателя за отсутствие надлежащего раскрытия у
партнёра, не только самого инфлюенсера. Проверка соблюдения —
обязательный пункт контракта/брифа с креатором, не предположение, что
креатор сам разберётся.

Для юрисдикций за пределами США — эквивалентные требования (например
рекламное законодательство ЕС/местных регуляторов) проверять отдельно,
этот раздел не покрывает их.

## Сетка ставок по тирам (ориентировочно, сильно варьируется по нише)

| Тир по аудитории | Ориентир подхода к ставке |
|---|---|
| Нано (1k-10k) | Часто продукт/небольшая оплата, высокое доверие аудитории |
| Микро (10k-100k) | Оплата за пост, договорная, эффективнее по цене за вовлечённость, чем крупные тиры |
| Мид (100k-1M) | Оплата ближе к рыночным медиа-ставкам, требует брифа и контроля качества |
| Макро/селебрити (1M+) | Высокая стоимость, охват часто важнее вовлечённости, для awareness-целей |

Ставки сильно зависят от ниши и платформы — таблица задаёт порядок
подхода (продукт vs оплата vs медиа-ставка), не конкретные цифры.

## Частые ошибки

- Отсутствие явного `#ad`-раскрытия в самом посте — юридический риск
  для бренда, не только для креатора.
- Выбор тира по размеру аудитории без учёта вовлечённости — крупный
  аккаунт с низким engagement rate часто хуже микро-инфлюенсера по
  реальному результату.
- Работа без брифа/контракта, фиксирующего требование раскрытия —
  полагаться на добросовестность креатора недостаточно с точки зрения
  ответственности бренда.
