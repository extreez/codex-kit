# События

## Четыре роли

| Роль | Инвестиция | Что даёт |
|---|---|---|
| **Host** (организовать своё) | Высокая (время, бюджет, риск явки) | Полный контроль над аудиторией и посылом, самый высокий потолок результата |
| **Sponsor** (спонсировать чужое) | Средняя-высокая (бюджет) | Доступ к чужой собранной аудитории без организационной нагрузки |
| **Speak** (выступить) | Средняя (время на подготовку) | Авторитет + прямой контакт с заинтересованной аудиторией, часто дешевле спонсорства |
| **Attend** (просто присутствовать) | Низкая | Нетворкинг, разведка рынка/конкурентов, минимальный прямой маркетинговый эффект |

Выбор роли — по цели и ресурсу, не по принципу «мы всегда спонсируем»
— speak часто даёт лучшее соотношение результата к затратам, если
есть, что сказать по существу.

## Правило «20% событие, 80% до и после»

Само событие — меньшая часть работы. Основной эффект строится:

- **До (большая часть 80%)**: анонс с достаточным упреждением,
  подготовка контента для распространения после, договорённости о
  встречах на месте, тизер-контент для тех, кто не идёт.
- **После**: репурпозинг (запись выступления → атомы для соцсетей, см.
  `social-media/social-content`), follow-up с контактами, отчёт для
  команды/руководства о результате.

Событие без плана «до» и «после» — потраченное время с эффектом,
ограниченным присутствующими в зале в моменте.

## Saturday Test (для community-событий)

Проверка идеи события перед организацией: «Придут ли эти люди в
субботу, если не будет ничего кроме самого события — без спонсорского
бесплатного алкоголя, без нетворкинг-обязательности от работы?» Если
ответ «нет» — событие держится на внешнем стимуле, не на реальном
интересе к теме, стоит пересмотреть формат или отменить.

## Частые ошибки

- Выбор роли (обычно sponsor) по инерции без сравнения с speak/host
  по соотношению цена/результат.
- Всё внимание уделяется самому дню события, план «до» слабый (поздний
  анонс), план «после» отсутствует вовсе.
- Community-событие организуется по шаблону конференции без проверки
  Saturday Test — люди приходят ради бонусов, не ради содержания.
