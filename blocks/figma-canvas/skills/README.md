# Почему часть скиллов не переведена

Общее для всех скиллов `figma-canvas`: короткие/концептуальные роутеры
переведены на русский, но плотный контент с точными числами, guard-
правилами, чек-листами или пронумерованными плейсхолдерами (`__UPPER_SNAKE__`)
оставлен на языке оригинала дословно. Вольный перевод рискует сдвинуть
число, разорвать нумерацию или незаметно ослабить guard-условие — риск
неоправдан ради читаемости.

Где именно и почему в конкретном файле — одна строка в начале самого
файла, ссылается сюда за общим объяснением.
