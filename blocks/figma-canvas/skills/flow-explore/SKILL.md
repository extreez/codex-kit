# Flow & Screen Exploration

Четыре независимых скилла для исследования вариантов на холсте, каждый в
своём файле рядом. Открой только тот файл, который отвечает запросу, и
следуй его шагам от начала до конца — не грузи остальные три.

| Запрос пользователя | Файл | Что делает |
|---|---|---|
| «два варианта флоу из описания», «пофлоучартить идею» | `text-to-flows.md` | из текста строит две структурно разные гипотезы флоу, lo-fi wireframe-рядами |
| «покажи альтернативы этого экрана» | `screen-alternatives.md` | стресс-тест текущего экрана + ровно 2 альтернативные структуры рядом с оригиналом |
| «сделай мобильную версию», «адаптируй под мобилку» | `desktop-to-mobile.md` | десктоп-фрейм → мобильный 390px, с паттернами по типам секций |
| «свяжи экраны стрелками», «коннекторы между экранами» | `connect-screens.md` | автоматическая сетка + коннекторы между экранами по секциям |

## Общее для всех четырёх

Инструменты: `use_figma`/`evaluate_script` официального Figma MCP (плагин
`figma`, см. блок `figma-mcp`). Оригинал/выбранный фрейм всегда остаётся
нетронутым — все четыре режима только добавляют новые узлы рядом, никогда
не переписывают вход.

Экономия токенов (действует во всех четырёх, особенно в `connect-screens.md`,
где это явно расписано): предпочитать один составной вызов
`evaluate_script`, который делает всю работу флоу целиком, а не серию
мелких round-trip'ов, и возвращать компактные сводки, а не полные дампы
узлов.
