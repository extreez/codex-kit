> Формула объединения оценок 4 субагентов marketing-audit в composite
> score. По образцу `geo-optimize/skills/geo-optimize/references/
> composite-score.md`, адаптировано под равные веса маркетинговых зон.

# Формула composite score — детали объединения

## Веса зон

| Зона | Вес | Источник компонента |
|---|---|---|
| Фундамент | 0.25 | `score` из `positioning-checker` |
| Контент | 0.25 | `score` из `content-checker` |
| Каналы | 0.25 | `score` из `channel-checker` |
| Реклама и CRO | 0.25 | `score` из `paid-cro-checker` |

## Формула

```
composite = 0.25 * positioning_score
          + 0.25 * content_score
          + 0.25 * channels_score
          + 0.25 * paid_cro_score
```

Итог округляется до целого, диапазон 0-100.

## Если агент не смог оценить зону

Не подставляй 0 молча — 0 читается как «зона провалена», а на деле
зона не проверялась (например, нет файла-трекера, потому что процесс
ведётся неформально). В отчёте помечай такую зону как `не проверено`,
считай composite по доступным зонам с перерасчётом весов
пропорционально (сумма весов проверенных зон = 100%), и явно указывай
в отчёте, что итоговый score частичный.

Пример: если `channels_score` не получен (нет никакого трекера
соцсетей/email), composite считается по оставшимся 3 зонам с весами,
нормированными к 1.0 (0.25/0.75 для каждой), и отчёт помечает итог как
«composite по 75% покрытия зон, каналы не проверены — нет трекера».

## Интерпретация диапазонов (ориентир, не строгая шкала)

- 80-100 — стек в порядке, точечные улучшения.
- 60-79 — есть системный пробел минимум в одной зоне (обычно —
  отсутствие трекера, не сама работа), стоит завести автоматику
  (`content-loop`/`paid-ads-loop`/`cro-funnel-loop`) для этой зоны.
- Ниже 60 — минимум две зоны требуют внимания, приоритизировать по
  Impact/Ease находок внутри каждой, не по самому низкому score
  (низкий score из-за отсутствия трекера — это про учёт, не про
  реальное состояние дел).

Этот скилл не задаёт порог для автоматической остановки цикла (в
отличие от `geo-loop`, где 70/100 — жёсткий критерий) — маркетинговое
здоровье не сводится к одному числу так же чисто, как GEO-цитируемость,
итоговое решение о приоритетах за владельцем проекта.
