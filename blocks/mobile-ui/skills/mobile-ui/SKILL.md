# mobile-ui

Ставится как есть через `npx skills add`, апстрим (`ceorkm/mobile-app-
ui-design`) не копируется. Ситуативный блок — не входит по умолчанию,
подключается, когда задача конкретно про мобильный экран.

## Установка

```bash
npx skills add ceorkm/mobile-app-ui-design
```

## Что внутри

Дизайн-паттерны топовых приложений (Airbnb, Duolingo, Spotify, Revolut,
Phantom). 5-шаговый процесс от контекста до полировки. Отраслевые
конвенции для 9+ индустрий (AI, крипто, финансы, здоровье и др.) в
`references/industry-conventions.md`. Эмоциональный дизайн — Peak-End
Rule, циклы обратной связи. Дизайн-система: типографика, цвет (правило
60/30/10), spacing (8-point grid). Реализация — React, Tailwind, паттерны
компонентов.

Ключевые законы дизайна из источника: правило thumb zone (основные
действия в нижней трети экрана), F-паттерн сканирования, максимум 4
размера шрифта и 2 начертания в иерархии.

## Соседние блоки

`swiftui-ui`/`material3-ui` (отдельные блоки) — то же самое, но
привязанное к конкретной нативной платформе (SwiftUI/Jetpack Compose) с
точными API. Этот блок — когда платформа не нативная или ещё не выбрана.
`web-fundamentals`/`web-taste` — те же принципы (гештальт, spacing,
типографика), но для веба, не мобильных нативных ограничений (thumb
zone, safe area).

## Проверяемый результат (для /loop-build)

Субъективно (эмоциональный дизайн, конвенции индустрии) — критерий это
вердикт verifier-subagent по 5-шаговому процессу из скилла, не команда.
Численные части (8pt grid, thumb zone) — проверяемы grep'ом по значениям
отступов/размеров тач-целей в коде.

## Несколько экранов сразу — распараллелить

Ревью/проектирование сразу нескольких экранов приложения — subagent на
экран, независимо, общих данных между экранами обычно нет.
