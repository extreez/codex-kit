# Словные таймкоды

Скилл даёт транскрипт речи с таймкодом на каждое слово в формате,
который читает `video-use`. Не анализирует, что происходит в кадре -
для этого `watch` в этом же блоке.

## Два источника

| Источник | Разделение по спикерам | Ключ | Стоимость |
|---|---|---|---|
| whisper.cpp (локально, по умолчанию) | нет | не нужен | бесплатно |
| ElevenLabs Scribe (по запросу) | да, плюс звуковые события | `ELEVENLABS_API_KEY` | около 0.4 доллара за час |

### whisper.cpp - по умолчанию

Локально, офлайн, бесплатно. Разделения реплик по спикерам не даёт.

**Установка, если его ещё нет.** Со встроенной графикой берётся
BLAS-сборка, она считает на процессоре и на 12 ядрах быстрее видеокарты.
Сборка с Vulkan имеет смысл только на дискретной видеокарте, замер и
ссылка в блоке `transcribe`.

Бинарники, 20 МБ:

```bash
curl -L -o whisper.zip https://github.com/ggml-org/whisper.cpp/releases/download/b4938/whisper-blas-bin-x64.zip
```

Модель, 141 МБ:

```bash
curl -L -o ggml-base.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base.bin
```

Архив распаковать в `C:\whisper\`, модель положить в
`C:\whisper\models\`. Нужный файл внутри архива называется
`Release/whisper-cli.exe`.

```bash
setx WHISPER_CLI_PATH "C:\whisper\Release\whisper-cli.exe"
```

```bash
setx WHISPER_MODEL "C:\whisper\models\ggml-base.bin"
```

**Какую модель брать.**

| Модель | Размер | Заметка |
|---|---|---|
| `ggml-base.bin` | 141 МБ | умолчание, 11 секунд речи за 3.7 секунды на 12 ядрах |
| `ggml-small.bin` | 465 МБ | точнее, примерно втрое дольше |
| `ggml-medium.bin` | 1.4 ГБ | ждать дольше, чем слушать, брать незачем |

Скилл обязан проверить обе переменные до запуска. Их нет значит сказать
пользователю, чего не хватает, и дать эти команды. Молча падать нельзя.

### ElevenLabs Scribe - второй способ

Даёт разделение по спикерам и звуковые события. Нужен ключ
`ELEVENLABS_API_KEY`, платно. Нет ключа или задача не требует спикеров
значит остаться на whisper.cpp.

## Подстановка вместо облака - ключевая часть

`video-use` держит транскрипты в `<edit_dir>/transcripts/<имя>.json`.
Дальше их читает `helpers/pack_transcripts.py` и делает
`takes_packed.md`, тот самый файл, по которому монтажный агент выбирает
склейки.

Скрипт `scripts/transcribe_local.py` кладёт результат whisper.cpp по
этому же пути в этом же формате. Ключ ElevenLabs не нужен нигде дальше
по цепочке.

**Важная тонкость, не перепутай.** Чужой `helpers/transcribe.py` требует
ключ **до** того, как посмотрит на кеш: `load_api_key()` вызывается в
`main()` раньше проверки существующего файла и завершает процесс, если
ключа нет. Кеш внутри у него есть, но добраться до него без ключа
нельзя.

Отсюда правило: `helpers/transcribe.py` **не запускать вообще**. Вместо
него сразу `transcribe_local.py`. Дальше цепочка идёт как обычно.

Проверено сквозным прогоном без ключа: 22 слова от whisper.cpp прошли
через `pack_transcripts.py --edit-dir` и дали корректный
`takes_packed.md` с фразой и диапазоном `[000.32-010.50]`.

```bash
python scripts/transcribe_local.py take01.mp4 --language ru
uv run python helpers/pack_transcripts.py --edit-dir take01_dir/edit
```

## Формат JSON

```json
{ "words": [ { "type": "word", "text": "привет",
               "start": 0.12, "end": 0.44,
               "speaker_id": "speaker_0" } ] }
```

Поле `speaker_id` необязательное, `video-use` читает его через `.get`.
Поле `type` бывает `word`, а также разделители и звуковые события -
их whisper.cpp не даёт, только ElevenLabs Scribe.

## Жёсткие правила

- Не запускать облачную транскрипцию, если локальной хватает на задачу.
- Не молчать про отсутствие разделения по спикерам, если пользователю
  оно нужно. Сказать прямо и предложить ElevenLabs Scribe.
- Проверить, что дорожка не пустая, до обработки.

## Соседние скиллы

Результат кормит `video-use` (автовырез тишины, субтитры) через кеш
транскриптов. `watch` (этот же блок) - для содержания видео, не для
словных таймкодов.
