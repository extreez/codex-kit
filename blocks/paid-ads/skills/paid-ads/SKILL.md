# Платная реклама

## Структура кампании

```
Аккаунт
 └─ Кампания (одна бизнес-цель: awareness/лидген/продажи)
     └─ Адсет (одна аудитория/таргетинг)
         └─ Объявление (один креатив, см. `ad-creative`)
```

Не смешивать цели в одной кампании — awareness и conversion-цель в
одной кампании конкурируют за бюджет и алгоритм оптимизирует не под
ту метрику, которая реально важна.

## Modern Meta playbook (Andromeda era, 2026+)

Meta перешла на алгоритм Andromeda — старая логика (детальный стек
интересов, полированное продакшн-видео как обязательное условие)
больше не определяет результат так, как раньше:

- **Таргетинг переносится в креатив**: «audience knowledge → creative
  first, targeting filters second». Порядок работы над кампанией
  меняется — сначала понимание аудитории закладывается в сам креатив
  (кто на видео, какой язык, какая ситуация), таргетинг-фильтры
  играют вторичную, уточняющую роль, не первичную.
- **Стек интересов больше не даёт преимущества** — узкое
  таргетирование по интересам может активно вредить (алгоритм ищет
  сигнал сам, излишние ограничения мешают ему найти конверсию).
- **Статика часто обгоняет видео** — не универсальное правило, но
  предположение «видео всегда лучше статики» больше не работает по
  умолчанию, тестировать оба формата без предвзятости.
- Ориентировочное распределение усилия: **80%+ на креатив, 20% на
  таргетинг-фильтры** — обратная пропорция тому, что было приоритетом
  до Andromeda.

## Платформенные плейбуки (кратко)

| Платформа | Специфика |
|---|---|
| **Meta** | Andromeda-era выше; сильна для B2C и широкой B2B-воронки верхнего уровня |
| **Google Search** | Интент уже явный (поисковый запрос) — текст объявления отвечает на конкретный запрос, не общий бренд-месседж; структура RSA (Responsive Search Ads) — несколько вариантов заголовков/описаний, алгоритм комбинирует |
| **LinkedIn** | Дорогой клик, но точный B2B-таргетинг по должности/компании — оправдан для высокого LTV сделки, не для дешёвого товара; формат нативный, не выглядящий как реклама, работает лучше явно рекламного |
| **ABM (Account-Based Marketing)** | Таргетинг на конкретный список компаний (не широкую аудиторию) — используется LinkedIn Matched Audiences/аналоги; креатив персонализирован под сегмент аккаунтов, не под персону в вакууме |

## Формулы текста объявления

| Формула | Структура |
|---|---|
| **PAS** | Problem → Agitate → Solution |
| **BAB** | Before → After → Bridge |

Выбор формулы зависит от стадии воронки (ниже) — PAS сильнее для
холодной аудитории, которая ещё не осознала проблему остро; BAB
сильнее для аудитории, уже понимающей проблему, но не видевшей
решение.

## Таргетинг по стадии воронки

| Стадия | Аудитория | Формула текста |
|---|---|---|
| Awareness (холодная) | Широкая, по демографии/интересам категории | PAS — сначала называем проблему |
| Consideration (тёплая) | Ретаргетинг посетителей сайта/вовлечённых с контентом | BAB — уже знают проблему, показываем путь |
| Decision (горячая) | Ретаргетинг с высоким интентом (посетили pricing, добавили в корзину) | Прямое предложение, снятие последнего возражения (см. `copywriting/copywriting`, секция Zero Risk) |

## Распределение бюджета: 70/30 test/proven

70% бюджета — на уже проверенные, стабильно работающие
кампании/креативы. 30% — на тестирование новых аудиторий/креативов/
форматов. Без выделенной доли на тесты кампания стагнирует, когда
проверенное неизбежно начинает уставать (creative fatigue); без
дисциплины 70% на проверенное — бюджет распыляется на непроверенные
гипотезы без стабильной базы результата.

## Частые ошибки

- Работа по старой логике Meta (узкий стек интересов, ставка только
  на видео) без учёта сдвига Andromeda — тратит бюджет на подход,
  который алгоритм больше не вознаграждает.
- Одна кампания с смешанными целями (awareness + conversion) —
  алгоритм оптимизирует под неверную метрику для части бюджета.
- Отсутствие доли бюджета на тесты (100% в «проверенное») — креатив
  устаёт, результат медленно падает без замены.
