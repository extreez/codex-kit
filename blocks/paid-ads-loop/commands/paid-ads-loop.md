Запусти цикл по скиллу `paid-ads-loop`.

Критерий остановки (проверяемый): в `docs/marketing/paid-ads-tests.md`
ни у одной строки с прошедшим плановым окончанием нет пустой колонки
«Решение».

Один проход:
1. Прочитать `docs/marketing/paid-ads-tests.md` (создать при первом
   запуске — колонки: Тест, Платформа, Начало, Плановое окончание,
   Решение).
2. Для каждого истёкшего теста без решения — прогнать
   `metrics/analytics-readback`, получить promote/rollback/нужно больше
   данных.
3. **Promote** → зафиксировать в `paid-ads/ad-creative` как выигравший
   угол, начать масштабирование (см. правило creative fatigue).
   **Rollback** → откатить бюджет на проверенный вариант, записать
   причину. **Нужно больше данных** → продлить окно, не закрывать
   строку.
4. Записать решение в таблицу и `docs/marketing/readback-log.md`.
5. Повторить, пока критерий не выполнен.

Спроси модель и эффорт под шаги (правило). Реальное изменение бюджета/
запуск нового креатива — только после подтверждения владельца, цикл
готовит решение и напоминает, не тратит бюджет самостоятельно.
