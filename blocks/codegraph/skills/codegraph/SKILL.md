# codegraph

Ставится как есть — MCP-сервер уже подключён `.mcp.json` этого блока, `npx`
сам подтянет пакет `@colbymchenry/codegraph` при первом обращении. Ставить
вручную ничего не нужно, кроме Node.js (обычно уже стоит вместе с Claude
Code). Никаких дополнительных сервисов (Docker и подобного) не требует.

## Прежде чем ставить

По сравнению задачи «карта кода» (`library/codebase-map/README.md`) этот
блок дублирует `repowise` без нового смысла: тот же граф зависимостей, но
без git-истории и health-score, которые уже даёт `repowise`. Ставить только
если `repowise` конкретно не подошёл — назвать причину.

## Конфликт

Одна задача с `repowise`, `socraticode`, `graphify`, `understand-anything` —
группа зафиксирована в `CONFLICTS.md`.
