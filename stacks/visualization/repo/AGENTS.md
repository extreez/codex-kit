Задача этой сессии: `docs/brief.md` - прочитай перед началом работы.

## Какой блок звать

- Связи, структура, порядок, состояния - `diagram-schemas` (архитектура,
  workflow, sequence, dataflow, lifecycle).
- Числа, сравнение величин, тренды, распределения - `chart-selection`
  (быстрая таблица выбора чарта) + встроенный `dataviz` (основной метод).
- Нужна карта реального репозитория, не диаграмма по описанию - сначала
  блок из группы `codebase-map` (`repowise`), потом уже её результат
  превращать в диаграмму через `diagram-schemas`.

Не рисуй диаграмму или чарт по данным, которые не можешь проверить - если
источник неясен, сначала спроси, потом рисуй.

## Готово, когда

Файл открывается в браузере без ошибок, самопроверка блока пройдена
(`self-check.md` у `diagram-schemas`, чек-лист честности данных у
`chart-selection`), результат лежит в `docs/`.
