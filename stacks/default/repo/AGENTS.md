# {{PROJECT_NAME}}

Тип: базовый проект без специализации.

## Где что лежит

| Путь | Что это |
|---|---|
| `.agents/settings.json` | права и подключённые блоки |
| `.agents/settings.local.json` | настройки только для этой машины |
| `.agents/rules/` | правила проекта, которые подключаются в контекст |
| `.agents/commands/` | слэш-команды проекта |
| `.agents/agents/` | агенты проекта |
| `.agents/skills/` | скиллы проекта |
| `.agents/hooks/` | хуки проекта |
| `.mcp.json` | MCP-серверы проекта, ключи — через `${ИМЯ_ПЕРЕМЕННОЙ}` |
| `AGENTS.local.md` | твои личные заметки по проекту |
| `.env` | секреты |

Блоки подключаются через `/kit add <блок>` и появляются в `.agents/settings.json`.

Вся обвязка Codex — `.agents/`, `AGENTS.md`, `.mcp.json`, `.env` — в git не едет:
она перечислена в `.gitignore`. На другой машине проект приедет без блоков,
вернуть их: `/kit apply <стек>`.
