# docs/marketing — правила каталога отчётов

Здесь живут брифы, контекст продукт-маркетинга (ссылка/копия
`.agents/product-marketing.md`), отчёты readback, боевые карточки,
контент-планы. Правила для агента, работающего в этой папке.

## Не разводить отчётность

- Один тип отчёта — один живой файл, обновляемый по месту
  (`positioning-map.md`, `battlecards/<конкурент>.md`,
  `content-calendar.md`), не новый файл на каждый прогон.
- Readback-записи (`metrics/analytics-readback`) — копить в одном
  файле `readback-log.md`, одна запись на изменение, не отдельный файл
  на каждую проверку.
- Устаревшее (позиционирование сменилось, конкурент ушёл с рынка) —
  удалять или явно помечать архивным, не копить мёртвые версии.

## Что оставлять

- Актуальную версию контекста продукт-маркетинга.
- Актуальные боевые карточки (обновление не реже раза в квартал —
  правило из `positioning/positioning-gtm`).
- Лог readback-решений с датами.

## Чего тут не делать

- Не хранить черновики постов/писем, ожидающие ручной отправки
  (`social-media/linkedin`, `email-outbound/cold-email`) дольше цикла
  их актуальности — устаревший неотправленный черновик вводит в
  заблуждение при следующем запуске скилла.
- Не коммитить персональные данные лидов/подписчиков — только
  агрегированные метрики.
