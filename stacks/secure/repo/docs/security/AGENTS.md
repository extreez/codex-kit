# docs/security — правила каталога отчётов

Здесь живут отчёты аудита (`audit-<дата>.md`) и красной команды. Правила для
агента, работающего в этой папке.

## Не разводить отчётность

- Один аудит — один файл `audit-<дата>.md`. Не плоди отчёт на каждый прогон
  зоны.
- Весь чеклист в статусе «закрыт» и находок ноль — не пиши толстый отчёт.
  Хватит строки в `LATEST.md`: дата, стек, «ноль находок, чеклист закрыт».
- Отчёт, потерявший актуальность (находки закрыты и перепроверены более свежим
  прогоном), — удаляй. Не держи историю ради истории: git помнит.
- Актуальным считается последний отчёт и любой с ещё открытыми находками.

## Что оставлять

- Последний аудит.
- Любой отчёт с незакрытыми CONFIRMED.
- `LATEST.md` — одна строка про текущее состояние.

## Чего тут не делать

- Не хранить сюда секреты, дампы, куски прод-данных. Только находки и статусы.
- Не коммитить сырой вывод сканеров целиком — только выжимку с файлом:строкой.
