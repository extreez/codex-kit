# deploy-vercel

Изложено своими словами по мотивам vercel-labs/agent-skills (репозиторий без файла
LICENSE - текст скилла не копируется дословно, здесь пересказана логика) и
официального CLI/доки Vercel.

## Шаг 0. Определить состояние проекта

Прежде чем что-то деплоить, проверь четыре факта:

1. Есть git remote у репозитория?
2. Проект уже слинкован с Vercel - есть `.vercel/project.json` (или `.vercel/repo.json` для монорепо)?
3. CLI авторизован - `vercel whoami` отвечает без ошибки?
4. Если команда/организация - какая (`vercel teams list`)?

По умолчанию - деплой preview, не production. На production - только если явно попросили.

## Шаг 1. Выбрать путь по дереву решений

| Слинкован | Git remote | Что делать |
|---|---|---|
| да | да | закоммитить и запушить - Vercel задеплоит сам по git-интеграции |
| да | нет | `vercel deploy --no-wait`, вернуть ссылку |
| нет | - | `vercel link --repo --scope <team>`, потом деплой |
| CLI не установлен | - | установить, `vercel login`, `vercel link`, деплой |

Без интерактивного логина (агентская песочница) - `vercel deploy` умеет работать
через отдельный `deploy.sh` без авторизации, который возвращает Preview URL и
Claim URL для последующей привязки к аккаунту.

## Шаг 2. Конфигурация проекта

`vercel.json` - маршруты (`rewrites`/`redirects`), крон-задачи
(`vercel crons add`, декларация в `crons`), заголовки. `vercel routes --ai
"..."` умеет сгенерировать правила роутинга по текстовому описанию.

## Шаг 3. После деплоя

Никогда не curl'ить задеплоенный URL для проверки - просто вернуть ссылку
пользователю. Проверка живости - его решение, не агента.

## Агентские возможности самого Vercel

Vercel публикует собственные инструменты для работы с агентами - учитывай, если
проект уже на Vercel:

- `vercel agent init` - генерирует `AGENTS.md` с best practices деплоя именно
  для кодинг-агентов
- `vercel skills` - каталог агентских скиллов под стек конкретного проекта
- `vercel mcp` - настройка MCP-клиента под проект
- `https://vercel.com/llms.txt` - машиночитаемый индекс документации (ссылки на
  OpenAPI-спеку, граф документации)

## Ошибки в песочнице claude.ai/Codex

Сетевой доступ к `*.vercel.com` может быть не открыт по умолчанию - первое, что
проверять при ошибке подключения CLI.

## Соседи

Другая платформа - `deploy-render`/`deploy-azure-appservice`/`deploy-expo-eas`/
`deploy-openship`, не альтернативы этому блоку, выбор идёт по факту проекта.

платформе - `deployment-readiness`.
