# seo-offpage

Три части: внутренняя ссылочная структура (что можно поправить сразу),
поиск внешних площадок (что предстоит сделать), оценка текущих внешних
сигналов (где сейчас домен).

## Часть 1. Внутренняя структура — hub-and-spoke, сироты, анкоры

### Hub-and-spoke аудит

Проверь, что ссылочный вес течёт по кластерам осмысленно (см. структуру
кластеров в `seo-content`): hub-страница линкует на все свои spoke, каждый
spoke линкует обратно на hub и на 1-2 соседних spoke по теме. Разрыв —
находка: spoke существует, но hub на него не ссылается (или наоборот).

### Orphan detection — сиротские страницы

Страница есть в sitemap/CMS, но ни одна другая страница сайта на неё не
ссылается — она не получает внутреннего ссылочного веса и её сложнее
обойти краулеру (пересекается с `seo-audit`, слой 1, CR-5 — тот же
признак, здесь смотрим на последствие для распределения веса, не только
для индексации). Список сирот — приоритетные кандидаты на добавление
ссылок с тематически близких страниц.

### Anchor audit — текст ссылок

Собери анкоры внутренних ссылок на каждую важную страницу:
- Разнообразие: не 100% одного и того же анкора на страницу (выглядит
  неестественно, размывает сигнал о теме страницы).
- Релевантность: анкор описывает, куда ведёт («сравнение тарифов CRM»),
  не generic («здесь», «подробнее», «читать дальше») на ссылках, где
  анкор мог бы нести смысл.
- Соответствие теме: анкор соответствует теме целевой страницы, не теме
  страницы-донора.

## Часть 2. Поиск площадок — link prospecting

Найти реальные кандидатов на внешнюю ссылку, а не абстрактный список
«качественных сайтов»:

1. **Linkable asset mapping** — сначала определи, что на сайте вообще
   достойно того, чтобы на него ссылались: оригинальное исследование,
   уникальные данные, инструмент/калькулятор, исчерпывающий гайд. Страница
   с продающим текстом без уникальной ценности линков не соберёт —
   не отправляй её в аутрич.
2. **Поиск доноров**: площадки, которые уже ссылаются на похожие ресурсы
   у конкурентов (тот же принцип, что gap-анализ в `seo-content` —
   сравнение с конкурентами), тематические каталоги/подборки, площадки,
   упоминающие тему без ссылки (можно предложить добавить).
3. **Prospect scoring** — не все кандидаты равны, оцени каждого по:
   тематической близости (тот же ниш/смежная), очевидным сигналам
   авторитетности (реальная аудитория/активность, не просто регистрация
   домена), реалистичности контакта (есть ли publicly способ связаться,
   принимает ли площадка гостевые материалы). Низкий score — не в
   приоритетный список для аутрича.

## Часть 3. Оценка внешних сигналов

Что смотреть по своему домену и по конкурентам (для сравнения):
- Количество и разнообразие ссылающихся доменов (не только количество
  ссылок — 100 ссылок с одного домена весят меньше, чем 20 с разных).
- Тематическая близость доноров к своей нише.
- Признаки токсичности: массовые ссылки с явно нерелевантных/спамных
  площадок, резкий неестественный скачок числа ссылок за короткий срок.
- Соотношение брендовых и точных анкоров во входящих ссылках (перекос в
  сторону точных коммерческих анкоров — сигнал риска для алгоритмов
  анти-спама, а не показатель силы).

## Отчёт

`docs/seo/offpage-<дата>.md`: находки по внутренней структуре (с
файлом/URL, как в `seo-audit`), список приоритетных доноров с scoring,
сводка по текущим внешним сигналам. Не смешивай «нашёл проблему» и «нашёл
возможность» в одном списке — это разные типы действий (фикс vs аутрич).

## Смежные блоки

`seo-audit` — та же сиротская страница с точки зрения индексации (слой
Crawlability). `seo-content` — linkable asset начинается с контентной
стратегии, этот скилл не создаёт материал, только оценивает и ищет
площадки под уже существующий.
