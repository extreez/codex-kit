# content-loop

Автоматизирует `content-strategy/content-governance` двумя механизмами:
гейт на выходе из сессии, цикл продвижения по стадиям. По образцу
`seo-loop`, адаптировано под жизненный цикл контента.

## Формат трекера

`docs/marketing/content-pipeline.md` — одна таблица, одна строка на
материал:

```markdown
| Тема | Stage | Дата входа в стадию | Дата публикации | Readback |
|---|---|---|---|---|
| Название статьи | REVIEW | 2026-09-01 | | |
| Другая статья | PUBLISHED | 2026-08-20 | 2026-08-22 | readback-log#3 |
```

Колонка Readback пустая до тех пор, пока `metrics/analytics-readback` не
прогнан по материалу — тогда туда вписывается ссылка на запись в
`docs/marketing/readback-log.md`.

## 1. Stop-гейт (хук, уже активен блоком)

Хук `stop-gate.js` парсит `docs/marketing/content-pipeline.md` (если
файла нет — не мешает) и блокирует конец сессии один раз, если находит
строку со Stage=PUBLISHED, дата публикации старше readback-окна
(по умолчанию 14 дней) и пустая колонка Readback. Грубая эвристика по
дате в тексте таблицы, не полноценный парсер markdown — при нестандартном
формате строки может не сработать, это нормально, не строгая проверка.

## 2. Цикл продвижения по стадиям

Крутит проход, пока критерий не выполнен (см. `commands/content-loop.md`
за точной формулировкой): ничего не зависло в DRAFT/REVIEW дольше
согласованного срока, и весь PUBLISHED старше окна имеет readback.

Один проход:
1. Прочитать трекер.
2. Продвинуть готовые материалы по стадии (черновик → редактура →
   ревью → одобрение → публикация, каждый переход — по решению
   владельца, не автоматически).
3. Закрыть readback по опубликованному старше окна.
4. Повторить.

Собирается через `/goal` и/или `/loop` (скилл `loop-build`). Условие
остановки — команда: перечитать трекер, посчитать зависшие строки,
должно быть 0.

Модель и эффорт под каждый шаг спрашиваются при запуске (правило).

## Границы

- Цикл не публикует материалы сам — только продвигает статус в
  трекере и напоминает про недостающий шаг (редактура/ревью/readback).
- Гейт только напоминает, не блокирует навсегда.
- Не путать с `cro-funnel-loop` (цикл диагностики воронки) и
  `paid-ads-loop` (цикл рекламных тестов) — разные объекты цикла.
