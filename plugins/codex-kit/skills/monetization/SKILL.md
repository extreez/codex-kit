# Монетизация

2 шаблона из `pm-skills` (phuryn) — разные вопросы: как вообще
зарабатывать (модель) и сколько просить (цена). Файлы в `templates/`
дословно на английском, атрибуция в начале каждого.

## Какой шаблон когда

| Запрос пользователя | Файл | Вопрос |
|---|---|---|
| «какую модель монетизации выбрать» | `templates/monetization-strategy.md` | 3-5 вариантов модели (подписка/freemium/транзакционная/реклама и т.д.) с аудиторией, рисками, экспериментом на проверку каждого |
| «спроектируй ценовую стратегию» / «freemium или платная подписка» | `templates/pricing-strategy.md` | Модель цены, конкурентный ценовой анализ, willingness-to-pay, эластичность |

## Как выбирать

`monetization-strategy` — раньше по времени, отвечает «как вообще
брать деньги» (несколько вариантов на выбор). `pricing-strategy` —
позже, когда модель уже выбрана, отвечает «сколько конкретно просить».
Не запускать `pricing-strategy` без выбранной модели монетизации —
сначала прогнать `monetization-strategy`, если модель ещё не решена.

Оба шаблона проектируют **стратегию** цены/модели по данным, которые
уже есть. Если данных о готовности платить (willingness-to-pay) нет —
их собирает `ux-research/pricing` (Van Westendorp/MaxDiff/Gabor-
Granger) в блоке `ux-research`, не этот блок. Порядок: сначала
исследование (`ux-research/pricing`), потом стратегия (здесь).
