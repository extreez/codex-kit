# Vision и value proposition

2 шаблона из `pm-skills` (phuryn) — короткие заявления, не полные
канвасы. Файлы в `templates/` дословно на английском, атрибуция в
начале каждого.

## Какой шаблон когда

| Запрос пользователя | Файл | Что даёт |
|---|---|---|
| «сформулируй product vision» | `templates/product-vision.md` | Вдохновляющая, достижимая, эмоциональная цель, объединяющая команду и стейкхолдеров |
| «напиши value proposition» / «почему клиент выберет нас» | `templates/value-proposition.md` | 6-частный JTBD-шаблон: Who / Why / What before / How / What after / Alternatives |

## Как выбирать

`product-vision` — внутрь команды (мотивация, направление), `value-
proposition` — наружу к клиенту (почему купить). Не подменять одно
другим — vision может быть амбициознее и абстрактнее, value
proposition должна быть конкретной и проверяемой на реальном клиенте.

Vision обычно пишется один раз на продукт/период и меняется редко,
value proposition — на каждый сегмент/JTBD отдельно, если сегментов
несколько.

Для полного стратегического канваса, куда обе эти вещи входят
секциями — см. `strategy-canvases` в этом же блоке.
