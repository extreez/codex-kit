# understand-anything

Не MCP и не CLI — свой плагин-маркетплейс Codex, отдельный от
codex-kit. Источник: https://github.com/Egonex-AI/Understand-Anything

## Единственный ручной шаг — и он не обходится

Слэш-команды набирает только пользователь, агент их из кода не вызывает
(то же ограничение, что у `/kit temp` в самом каталоге). Установка — два
слэш-команды, попроси пользователя выполнить один раз:

```
/plugin marketplace add Egonex-AI/Understand-Anything
/plugin install understand-anything
```

После этого — уже свои команды, без обвязки codex-kit:

```
/understand              # первичный анализ
/understand-dashboard    # открыть дашборд
```

## Прежде чем ставить

По сравнению задачи «карта кода» (`library/codebase-map/README.md`) — самый
дорогой вариант: LLM-вызовы на анализ бизнес-логики поверх статического
разбора, дашборд заточен под чтение человеком в браузере, не под точечные
запросы агента. Для того, что даёт `repowise` (дёшево, для агента),
избыточен. Годится, если нужен именно разбор бизнес-логики для человека,
не структурный граф.

## Конфликт

Одна задача с `repowise`, `socraticode`, `codegraph`, `graphify` — группа
зафиксирована в `CONFLICTS.md`.
