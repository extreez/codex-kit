# Управление людьми

6 инструментов из `Owl-Listener/design-leadership-skills`, изначально
под дизайн-лида, применимо к любому линейному менеджеру. Файлы в
`templates/` дословно на английском, атрибуция в начале каждого.

## Какой инструмент когда

| Запрос пользователя | Файл | Что даёт |
|---|---|---|
| «определи карьерную лестницу» | `templates/career-ladder.md` | Уровни по craft/scope/impact/collaboration/leadership как наблюдаемое поведение, IC- и менеджерский трек равноценны |
| «подготовь тяжёлый разговор» | `templates/difficult-conversation.md` | Purpose/facts/их точка зрения/opening line → прямое, но уважительное проведение |
| «дай фидбек» | `templates/feedback-delivery.md` | SBI (Situation/Behaviour/Impact) → спросить их взгляд → согласовать следующий шаг |
| «составь план роста» | `templates/growth-plan.md` | Аспирация человека → сильные стороны → 1-2 зоны роста → реальная stretch-работа → явная роль спонсора |
| «структурируй 1:1» | `templates/one-on-one.md` | Их встреча, не статус: как дела на самом деле → их повестка → блокеры → рост и фидбек в обе стороны |
| «напиши performance review» | `templates/performance-review.md` | Факты за весь период (не последний месяц) → career ladder как мерило → проверка на bias (recency, halo/horns, similarity-to-me) |

## Как выбирать

`feedback-delivery` — конкретный момент, `one-on-one` — регулярный
канал, `performance-review` — итог периода. Использовать
`feedback-delivery` сразу после события, не копить до review — review
документирует год фидбека, не заменяет его.

`difficult-conversation` — когда разговор один тяжёлый и разовый
(конфликт, увольнение, плохая новость). Если ситуация повторяющаяся
(хроническое качество работы) — сначала `feedback-delivery` несколько
раз, `difficult-conversation` только когда обычный фидбек не сработал.

Источники предполагают контекст дизайн-команды («designer», «IC vs
management track в дизайне») — методика переносится на инженерию,
продукт, любую функцию без изменений сути, менять нужно только
предметную область в формулировках.
