# Как оценивать находку

Стандарт для всего стека `secure`. Чеклист говорит ЧТО искать, этот файл — как
оценить найденное и что не считать находкой. Взято из практики Cloudflare
security-audit, адаптировано.

Цель — не раздуть отчёт. Аудит, который списком вывалил все отклонения от OWASP,
бесполезен: важное тонет.

## Шкала серьёзности

| Уровень | Что это |
|---|---|
| **CRITICAL** | RCE без аутентификации, полный дамп БД, захват админа без учётки |
| **HIGH** | RCE с аутентификацией, SQL-инъекция с выгрузкой, хранимый XSS на всех, полный обход прав с реальными последствиями |
| **MEDIUM** | точечный XSS, CSRF со сменой состояния, утечка учётки, обход бизнес-логики (нужна аутентификация, узкий охват) |
| **LOW** | утечка не-секретных данных, DoS ценой больших усилий |
| **INFORMATIONAL** | подтверждённая находка с минимальным влиянием; полезна как кирпич для другой |

RCE — выполнение чужого кода на сервере. RBAC — модель ролей и прав.

## Правило слоёв (defense-in-depth)

Слой A уже закрывает атаку — отсутствие слоя B это **заметка на хардненинг**, не
уязвимость. Не рейти дыру в многослойной защите как HIGH/CRITICAL.

Пример границы: параметризованный запрос уже стоит (IN-1 закрыт) — отсутствие
дополнительной валидации типа не уязвимость, а пожелание.

## Каждая находка — конкретный эксплойт

Не «теоретически возможно». Находка = профиль атакующего + действие + результат.
«Отправь этот запрос — получишь этот ответ» весит больше десяти «potentially».

Нет воспроизведения — помечай `requires testing`, не выдавай за подтверждённое.

## Что находкой НЕ является

- Отклонение от OWASP само по себе, без пути эксплуатации.
- Дыра в слое при живом соседнем слое (см. правило слоёв) — это хардненинг-заметка.
- Спроектированное поведение, названное багом.
- «Potentially / theoretically» без доказательства.
- Эксплойт, построенный на непроверенном предположении о парсере/библиотеке.

## Калибровка по классу приложения

Сравнивай с типичными приложениями того же рода: CMS с CMS, API-шлюз со шлюзом.
Так отличишь реально эксплуатируемое от индустриальной нормы.
