# Превиз камеры в Blender

Скилл строит камеру и её траекторию в Blender через MCP и отдаёт кадры с
этой траектории плюс словесное описание движения. Видео сам не рендерит -
финальный кадр всегда идёт через kie.ai.

## Подключение

Официальный MCP от Blender Foundation, репозиторий
`projects.blender.org/lab/blender_mcp`. У пользователя уже подключён,
переустанавливать не нужно.

## Инструменты

| Инструмент | Что даёт |
|---|---|
| `execute_blender_code_for_cli` | Python в фоновом Blender, окно не нужно |
| `execute_blender_code` | Python в открытом Blender |
| `render_thumbnail_to_path` | быстрый черновой кадр |
| `render_viewport_to_path` | рендер сцены в файл |
| `get_screenshot_of_window_as_image` | скриншот, агент видит результат |
| `search_api_docs`, `get_python_api_docs` | справочник bpy внутри MCP |
| `get_objects_summary`, `get_object_detail_summary` | разбор сцены |

Основной режим - фоновый, через `_for_cli`. Открытый Blender нужен только
когда пользователь смотрит сцену и правит её руками.

## Что скилл отдаёт на выходе

Набор кадров с траектории камеры плюс описание движения словами. Кадры идут
в промпт image-to-video на kie.ai как опора, либо в раскадровку как план
плана.

## Железо

У пользователя нет дискретной видеокарты, только встроенная Intel Iris Xe.
Eevee и превиз работают на этом железе нормально. Финальный рендер в
Blender не делаем - это не роль превиза в пайплайне, финал собирает
HyperFrames поверх генерации kie.ai.

## Безопасность

Официальный MCP исполняет код от модели без проверок - это написано в его
собственной документации. Не запускать код, который трогает файлы вне
папки проекта.

## Правило против выдумок

Перед тем как писать код на `bpy`, искать нужную функцию через
`search_api_docs`. Не звать функции bpy по памяти - API меняется между
версиями Blender, и неверный вызов падает без явной причины.

## Жёсткие правила

Превиз необязателен - не навязывать его в каждом проекте, только когда
камеру нельзя описать промптом. Не рендерить финал в Blender. Не открывать
Blender, если хватает фонового режима через `_for_cli`.

## Соседние скиллы

До: `storyboard` - превиз строится под утверждённые планы, не раньше. После:
кадры превиза идут в генерацию шотов (creative-skill, kie.ai) как опорные
изображения для image-to-video.
