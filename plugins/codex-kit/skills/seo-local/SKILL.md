# seo-local

Локальный SEO — не уменьшенная версия обычного SEO, а отдельный набор
сигналов вокруг карточки компании и согласованности данных о ней по сети.

## GBP-аудит (Google Business Profile)

Проверить по карточке:
- **Категория** — основная категория точно соответствует бизнесу, не
  ближайшая похожая (неточная категория снижает релевантность по
  локальным запросам).
- **NAP на карточке** совпадает с сайтом (см. ниже, NAP consistency).
- **Часы работы** актуальны, включая праздничные исключения.
- **Фото** — актуальны, есть фото интерьера/экстерьера/продукта, не
  только логотип.
- **Описание** — заполнено, не keyword stuffing, отражает реальные услуги.
- **Отзывы** — есть регулярный поток новых отзывов (не только старые),
  есть ответы владельца на отзывы (особенно негативные — отсутствие
  ответа на негатив хуже, чем сам негатив).
- **Posts/обновления** (если платформа поддерживает) — используются, не
  заброшены.
- **Q&A секция** — нет неотвеченных вопросов, нет ложной информации от
  третьих лиц без исправления.

## NAP consistency — Name, Address, Phone

Название, адрес и телефон должны совпадать буква в букву (включая формат
сокращений — «ул.» vs «улица», «д.» vs «дом») везде, где компания
упомянута: сайт (обычно в футере/странице контактов), Google Business
Profile, отраслевые каталоги, соцсети.

Проверка: собрать все упоминания NAP по известным площадкам, свести в
таблицу, отметить расхождения. Расхождение — не мелочь: поисковик
использует согласованность NAP как сигнал доверия к тому, что это одна и
та же реальная компания, а не мошенническая копия.

| Площадка | Name | Address | Phone | Совпадает с эталоном |
|---|---|---|---|---|
| Сайт (эталон) | | | | — |
| Google Business Profile | | | | да/нет |
| [каталог 1] | | | | да/нет |

## Стратегия цитирований (citations)

Цитирование — упоминание NAP компании на внешней площадке (каталог,
отраслевой справочник, локальная пресса), необязательно со ссылкой.

1. **Базовые цитирования** — отраслевые и общие бизнес-каталоги,
   релевантные региону и нише. Приоритет — площадки, которые сама
   поисковая система индексирует и которым доверяет (не любая ссылочная
   ферма).
2. **Нишевые цитирования** — отраслевые справочники конкретной сферы
   (для ресторана — агрегаторы доставки/отзывов, для медицины —
   медицинские каталоги).
3. **Согласованность превыше количества** — 10 цитирований с идеальным
   NAP лучше 50 с расхождениями. Перед добавлением нового цитирования
   свериться с эталонным NAP из таблицы выше.
4. **Локальные ссылки** — упоминания от локальных СМИ, партнёрских
   организаций, участие в местных мероприятиях с последующим упоминанием
   на их сайте — сигнал сильнее общего каталога.

## Отчёт

`docs/seo/local-<дата>.md`: статус GBP-аудита по пунктам, таблица NAP
consistency с расхождениями, список существующих и рекомендованных
цитирований.

## Смежные блоки

`seo-audit` — технические сигналы сайта, которые тоже влияют на локальную
выдачу (структурированные данные `LocalBusiness`, скорость страницы
контактов). `seo-offpage` — общая механика поиска площадок для ссылок,
здесь применяется к площадкам-цитированиям.
