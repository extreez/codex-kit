# Бесплатные инструменты и лид-магниты

## Различие форматов

| | Lead magnet | Free tool |
|---|---|---|
| Формат | Статичный контент (PDF, шаблон, mini-course) | Интерактивный (калькулятор, генератор, чекер) |
| Стоимость создания | Низкая-средняя (написать/оформить один раз) | Средняя-высокая (нужна разработка) |
| Ценность для SEO | Умеренная (одна страница-лендинг) | Высокая — сам инструмент может ранжироваться и получать органический трафик на постоянной основе |
| Повторное использование посетителем | Разовое скачивание | Может возвращаться повторно (bookmark-worthy) |

Не взаимозаменяемы: lead magnet быстрее сделать, free tool даёт более
долгий маркетинговый актив при большей инвестиции.

## Оценка идеи free tool (6 факторов)

| Фактор | Вопрос | Вес в оценке |
|---|---|---|
| Объём поиска | Есть ли реальный поисковый спрос на «X calculator/checker/generator» в нише? | Высокий |
| Конкуренция | Сколько уже существует похожих бесплатных инструментов в выдаче? | Высокий (обратный — чем больше конкуренции, тем ниже оценка) |
| Вирусность | Есть ли естественный повод поделиться результатом (например «мой score» шарится в соцсетях)? | Средний |
| Сложность реализации | Сколько разработки нужно — простой калькулятор против инструмента с базой данных | Средний (обратный) |
| Связь с продуктом | Логически ли инструмент подводит к основному продукту (не случайная тема) | Высокий |
| Долговечность | Не устареет ли инструмент быстро (например завязан на актуальные цифры года) | Средний |

Порог для запуска в разработку: **25+ баллов** из условной шкалы (по
сумме факторов, взвешенных по важности выше) — идея ниже порога
вероятно не окупит вложение в разработку относительно простого
lead magnet на ту же тему.

## UX-принципы free tool

- **До 3 полей ввода** до получения результата — каждое дополнительное
  поле теряет часть посетителей до того, как они увидели ценность.
- **Мобильный-первый** — многие переходы на бесплатный инструмент идут
  из соцсетей на мобильном, интерфейс должен работать без масштабирования.
- **Результат виден без регистрации** — гейтинг самого результата убивает
  смысл free tool как маркетингового актива; email можно запросить
  после показа результата («отправить отчёт на почту»), не до него.

## Lead magnet: привязка к стадии покупателя

| Стадия | Тип магнита |
|---|---|
| Awareness (только осознал проблему) | Образовательный чеклист/гайд — общий, не продуктовый |
| Consideration (сравнивает решения) | Шаблон/фреймворк, встраивающий продукт как один из способов решения |
| Decision (готов выбирать) | Демо-доступ, кейс-стади, калькулятор ROI конкретно под продукт |

Магнит не под стадию аудитории (например продуктовый калькулятор ROI
для холодной awareness-аудитории, которая ещё не осознала проблему)
собирает лиды низкого качества — заполняют форму из любопытства, не
из готовности покупать.

## Гейтинг

Решение гейтить контент (требовать email) — компромисс объёма лидов
против их качества: негейтированный контент даёт больше трафика и
SEO-ценности, гейтированный — меньше охвата, но список контактов.
Для free tools по умолчанию не гейтировать сам результат (см. выше).

## Частые ошибки

- Free tool строится без проверки объёма поиска — инструмент технически
  хороший, но искать его некому.
- Лид-магнит не соответствует стадии покупателя — собирает лиды,
  которые ещё далеко от готовности к покупке.
- Гейтинг результата free tool — убивает вирусный/SEO-потенциал
  формата, превращая его в обычную форму с дополнительным шагом.
