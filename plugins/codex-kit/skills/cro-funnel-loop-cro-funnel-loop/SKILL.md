Запусти цикл по скиллу `cro-funnel-loop`.

Критерий остановки (проверяемый): ноль находок `priority: High` в
последнем бэклоге `/cro-funnel` (docs/marketing/cro-funnel-backlog.md,
если ведётся — иначе в выводе последнего прохода команды).

Один проход: `/cro-funnel` (вся воронка или изменённая зона) → на каждую
находку High → фикс → повторный обход изменённой зоны → снова
`/cro-funnel` по этой зоне. Ноль High — стоп.

Спроси модель и эффорт под шаги (правило). Фикс воронки — реальное
изменение флоу (форма, шаг онбординга, момент показа paywall), не
косметика — предупреди владельца перед правкой логики регистрации/оплаты,
не переписывай без подтверждения.
