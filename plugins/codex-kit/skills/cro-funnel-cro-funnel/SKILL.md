Запусти диагностику по скиллу `cro-funnel`.

Обязательно:
1. Сначала спроси модель и эффорт под 3 субагентов (правило).
2. Если аргумент указывает конкретную зону — запусти только
   соответствующего агента. Иначе запусти `activation-checker`,
   `monetization-checker`, `page-form-checker` параллельно, каждый
   недоверчиво по своей зоне.
3. Объедини находки всех агентов в один бэклог, отсортированный по
   Priority (High → Medium → Low), не по зоне.
4. Отчёт: таблица находок (Zone/Issue/Impact/Fix/Priority) + раздел
   «не проверено» из всех агентов.

Не чини находки в этом проходе. Только диагностика и приоритизированный
бэклог — фикс делает владелец проекта или отдельный проход по
конкретной находке.
