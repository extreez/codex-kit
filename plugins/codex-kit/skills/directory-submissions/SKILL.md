# Листинги в директориях

## Чек-лист готовности (9 вопросов)

1. Продукт доступен без ожидания (не «запишитесь в лист ожидания» —
   директории ждут рабочую ссылку)?
2. Есть ли материалы под формат площадки (скриншоты, короткое видео,
   логотип нужного размера)?
3. Готов ли текст описания под ограничение символов площадки?
4. Есть ли команда/сообщество, готовые поддержать активность в день
   запуска (не для накрутки — для реальных ответов на вопросы)?
5. Определён ли один явный CTA после клика с площадки?
6. Проверена ли аналитика для отслеживания трафика именно с этой
   площадки?
7. Выбрана ли дата без конфликта с крупными запусками конкурентов/
   отраслевыми событиями в тот же день?
8. Подготовлен ли ответ на типичные возражения в комментариях
   заранее?
9. Есть ли план на «не выстрелило» — что делать, если охват ниже
   ожидаемого?

## Product Hunt (алгоритм 2026)

Алгоритм весит **качество комментариев выше количества апвоутов** —
короткое «Круто, апнул!» весит меньше, чем содержательный комментарий
с вопросом/наблюдением. Стратегия дня запуска: не просить массово
голосовать, а вовлекать в содержательное обсуждение — отвечать на
каждый комментарий развёрнуто, задавать встречные вопросы.

Важно тайминг: запуск в полночь по тихоокеанскому времени (начало
суток площадки) даёт максимум времени в топе за день.

## Протокол «10-в-30» (G2/Capterra)

Цель — собрать **10 отзывов за 30 дней** после запуска инициативы сбора
отзывов, не растягивать на неопределённый срок:

1. Сегментировать активных довольных клиентов (по health score или
   NPS-промоутерам, см. `retention-growth/churn-prevention`).
2. Личный запрос (не массовая рассылка) с прямой ссылкой на форму
   отзыва конкретной площадки.
3. Не предлагать материальное вознаграждение за отзыв там, где это
   запрещено правилами площадки (проверить политику G2/Capterra
   перед стимулированием).
4. Фоллоу-ап через 5-7 дней тем, кто не ответил, один раз.

## AI-директории и MCP-реестры

Новый тир площадок (директории AI-инструментов, реестры MCP-серверов)
— растущий канал для технических продуктов, роль похожа на Product
Hunt для этой узкой аудитории: качество описания и демо важнее объёма
маркетингового текста.

## Частые ошибки

- Запуск на Product Hunt с призывом «просто апните» — низкое качество
  вовлечённости не даёт алгоритмического буста при новой модели
  оценки.
- Массовая безличная рассылка с просьбой оставить отзыв — низкий
  response rate по сравнению с личным точечным запросом.
- Материальное стимулирование отзывов там, где это нарушает правила
  площадки — риск удаления отзывов или бана аккаунта компании.

   запуску?
3. Есть ли база активных довольных клиентов для запроса отзывов?
