# socraticode

Ставится как есть — MCP-сервер уже подключён `.mcp.json` этого блока, `npx`
сам подтянет пакет при первом обращении. Ставить вручную ничего не нужно,
кроме Node.js 18+ (обычно уже стоит вместе с Codex) и Docker.

## Docker — единственное, что проверяется

Хук блока при старте сессии скажет, запущен ли Docker (нужен для Qdrant и
Ollama внутри сервера). Не запущен — попроси пользователя включить Docker
Desktop (или демон на Linux), сам агент это не делает. После — MCP просто
работает, npx возьмёт пакет `socraticode` сам.

## Первая индексация

```bash
npx socraticode index   # или через MCP-инструмент codebase_index, если сервер уже поднят
```

Индексация фоновая, с чекпоинтами — можно прерывать и продолжать.

## Когда брать вместо repowise

`repowise` — рекомендованный выбор задачи «карта кода» (см.
`library/codebase-map/README.md`). `socraticode` берётся вместо него, если
нужен именно смысловой поиск или индексация не-кодовых артефактов — то, чего
у repowise нет.

## Конфликт

Одна задача с `repowise`, `codegraph`, `graphify`, `understand-anything` —
группа зафиксирована в `CONFLICTS.md`. Больше одного в проекте одновременно
не ставить, все индексируют один и тот же код.
