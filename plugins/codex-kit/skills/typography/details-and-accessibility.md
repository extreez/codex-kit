# Детали и доступность

Подчёркивания, выделение, формы, декоративный текст и полы, держащие всё
читаемым.

## Подчёркивания

Дефолтная позиция подчёркивания решается браузером — иногда слишком
близко, иногда режет descender'ы, иногда слишком тонкая. Брать позицию и
толщину из метрик самого шрифта:

```css
a {
  text-underline-position: from-font;
  text-decoration-thickness: from-font;
}
```

Пунктирное подчёркивание на аббревиатуре:

```css
abbr {
  text-decoration: underline dotted;
}
```

Или настроить вручную:

```css
a {
  text-decoration-thickness: 1px;
  text-underline-offset: 3px;
  text-decoration-skip-ink: auto;
  text-decoration-color: var(--color-gray-1000);
  transition: text-decoration-color 200ms ease-out;
}

a:hover {
  text-decoration-color: var(--color-gray-1200);
}
```

Кастомный элемент анимировать как требует эффект.

## Выделение

- `::target-text` стилизует фразу, к которой скроллит shared-ссылка.
- Custom Highlight API стилизует произвольно выбранные диапазоны, вроде
  совпадений поиска, без дополнительной разметки.

## Формы и редактируемый текст

- `::placeholder` стилизует подсказку в пустом поле.
- `caret-color` красит мигающий курсор ввода. Кастомизация каретки этим
  почти и ограничивается — полностью кастомный курсор сложно строить и
  редко того стоит.

### Зум инпутов на iOS

Это фича доступности: `16px` — веб-дефолт, Safari считает более мелкий
текст слишком сложным для чтения при вводе.

Два фикса отличаются тем, что делают с дизайном, не правильностью.

**Увеличить на мобильном.** Инпут рендерится на `16px` на мелких экранах,
падает до дизайнерского размера от breakpoint `sm`. Ничего компенсировать
не нужно, но мобильный инпут больше не совпадает с десктопным.

```tsx
<input className="text-base sm:text-sm" type="email" />
```

**Уменьшить текст трансформом.** Держать `font-size` на `16px`, чтобы
Safari никогда не зумил, рендерить нужный размер через transform. Дизайн
переживает любой viewport ценой двух компенсирующих вычислений. Расширить
элемент на обратный масштаб, чтобы он всё ещё заполнял контейнер после
сжатия, разделить `line-height` на тот же коэффициент, чтобы задуманный
leading сохранился. `origin-left` фиксирует текст к начальному краю,
`origin-right` — под RTL. Выше breakpoint — убрать transform, задать
реальный размер.

```tsx
// 13px, отрендеренные из font-size 16px: 13 / 16 = 0.8125
<div className="flex h-10 items-center rounded-[10px] bg-gray-300 px-2.5">
  <input
    className="h-full w-[calc(100%/0.8125)] origin-left scale-[0.8125] bg-transparent text-base leading-[calc(1.125/0.8125)] outline-none sm:w-full sm:scale-100 sm:text-[13px]"
    type="email"
  />
</div>
```

Трансформ сжимает весь блок, не только глифы, так что рисовать
поверхность поля должен обёртка, а инпут оставаться прозрачным. Фон,
граница или ring на трансформированном элементе сжимаются вместе с
текстом и промахивают задуманную hit-area.

## Декоративный текст

| Свойство | Эффект |
| --- | --- |
| `::first-letter` | Буквица, широкая поддержка |
| `::first-line` | Стилизует только первую строку |
| `initial-letter` | Задаёт размер буквицы; ограниченная поддержка, пока без Firefox |
| `background-clip: text` | Обрезает фон или градиент по форме букв |
| `-webkit-text-stroke` | Обводка букв; работает в современных браузерах несмотря на префикс |
| `text-shadow` | Как `box-shadow`, но следует форме символов |

Обводка текста, рисующая линии внутри букв — это шрифт. Обводка
повторяет каждый контур, и переменные шрифты обычно держат перекрывающиеся
формы неслитыми. У статичных шрифтов этой проблемы нет.

## Размеры

Типографика должна пережить смену читателем: зум, увеличенный шрифт
браузера, переопределённый line-height или letter-spacing.

| Текст | Размер |
| --- | --- |
| Отправная точка длинноформатного текста | Около `16px`, проверено на реальном шрифте и measure |
| Отправная точка инпутов и меню | Около `14px` |
| Подписи | `13px` |
| Пол | Редко ниже `12px` |

## Сглаживание шрифта

Tailwind-класс `antialiased` задаёт оба свойства:

```css
html {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

```tsx
<html lang="en">
  <body class="font-sans antialiased">
    <main>{children}</main>
  </body>
</html>
```
