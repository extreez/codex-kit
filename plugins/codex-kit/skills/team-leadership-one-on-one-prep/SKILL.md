Прогони один проход по скиллу `people-management` в блоке
`team-leadership`, раздел `templates/one-on-one.md`.

Предназначено для повторного запуска через `/loop <интервал>
/one-on-one-prep <имя>` (например раз в неделю или раз в две недели —
пользователь выбирает интервал под свой каданс 1:1 с конкретным
человеком). Каждый запуск — подготовка к одной конкретной встрече, не
архив всех прошлых.

Если пользователь ведёт заметки по 1:1 в файле (например
`1-1-[имя].md`) — прочитать его перед подготовкой, унести открытые
темы из прошлой встречи в повестку этой (источник прямо требует:
держать общий документ, чтобы ничего не терялось незамеченным).

Структура одного прохода — по source-шаблону: как дела на самом деле →
их повестка → блокеры, которые можешь снять → рост и фидбек в обе
стороны → что стоит спросить, но не спрашиваешь. Это их встреча — не
готовить статус-апдейт вместо повестки человека.

Модель/эффорт не спрашивать — регулярная короткая подготовка без
субагентов.
