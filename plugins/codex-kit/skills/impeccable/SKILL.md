# impeccable

Ставится как есть, апстрим ничего не синтезируется и не копируется в этот
блок — здесь только инструкция по установке и краткий указатель, что где
искать. Правки самого инструмента идут только через апстрим-репозиторий, не
через codex-kit.

## Установка

```bash
npx impeccable install
```

Один раз в начале работы над проектом:

```
/impeccable init
```

Собирает `PRODUCT.md` (аудитория, голос, ограничения) — держит его
дюрабельным контекстом для всех последующих команд.

## Когда какая команда

| Момент | Команда | Что делает |
|---|---|---|
| Старт нового направления | `/impeccable new-work` | калибровка против AI-клише по умолчанию (список запрещённых по умолчанию шрифтов, культурные миры на выбор через рандомизацию, отдельная калибровка под саму модель) |
| Раздел выглядит плоско/скучно | `/impeccable bolder` | усиление в рамках уже существующей поверхности, не миграция на новую идею |
| Слишком шумно/ярко | `/impeccable quieter` | снижение насыщенности до 70-85%, толщины шрифта, длины движения |
| Слишком сложно | `/impeccable distill` | палитра до 1-2 цветов + нейтрали, один шрифт, без вложенных карточек |
| Задуман тяжёлый эффект | `/impeccable overdrive` | требует предложить 2-3 направления до кода, тест на удаление |
| Готовый экран | `/impeccable audit` / `polish` | 5-балльная оценка по 5 измерениям, триаж дрейфа |
| Цвет/типографика отдельно | `/impeccable colorize` / `typeset` | роли, не мешок цветов; раздельные проходы (человеческая оценка + механический скан) |

Полный список 23 команд и офлайн-детектор на 61 правило (`side-tab`,
`gradient-text`, `bounce-easing` и т.д.) — в самом установленном дистрибутиве
(`dist/claude/`), не дублируется здесь.

## Соседние блоки

`taste-skill` — параметризация брифа числовыми dial'ами, работает *до* того,
как impeccable начинает калибровку/ревью, не конкурент. `web-taste` — синтез
из других источников (craft-review/gate-check), не пересекается с командами
impeccable напрямую, ссылается на них как на отдельный, самодостаточный
инструмент.

## Проверяемый результат (для /loop-build)

Уже готовая команда — `impeccable audit` (или соответствующая команда из
23) возвращает список нарушений; готово, когда список пуст / exit-код 0.
Самый честный критерий во всём каталоге — детерминированные детекторы,
не суждение.

## Несколько файлов сразу — не нужно

CLI уже сканирует пакетно сам по себе — это его прямая работа, заводить
agent-параллелизацию поверх него избыточно, инструмент это уже умеет.
