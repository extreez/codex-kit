# Личная практика лидера

5 инструментов из `Owl-Listener/design-leadership-skills`, ни один не
привязан к дизайну — применимо к любому лидеру любой функции без
адаптации. Файлы в `templates/` дословно на английском, атрибуция в
начале каждого.

## Какой инструмент когда

| Запрос пользователя | Файл | Что даёт |
|---|---|---|
| «проведи команду через изменения» | `templates/change-leadership.md` | Почему раньше что → честно назвать потерю → конкретное будущее → вовлечь в «как» → ранние победы → повторять сообщение чаще, чем кажется нужным |
| «разреши конфликт» | `templates/conflict-resolution.md` | Вывести конфликт наружу → выслушать стороны раздельно → найти общую цель → интересы, не позиции → договорённость с конкретикой, потом фоллоу-ап |
| «реши этическую дилемму» | `templates/leadership-ethics.md` | Назвать напряжение прямо (пользователи vs метрики, честность vs комфорт) → кто может пострадать и как → озвучить рано и письменно |
| «как менторить» | `templates/mentorship.md` | Coaching (вопросы, растят суждение) / advising (делишься опытом) / sponsoring (продвигаешь в комнатах без них) / connecting — от их цели, не от твоей повестки |
| «управляй своим временем как лидер» | `templates/self-leadership.md` | Время/энергия/внимание/границы/рефлексия — команда копирует твой темп, не только слова |

## Как выбирать

`conflict-resolution` — между конкретными людьми/командами здесь и
сейчас. `leadership-ethics` — про принципиальное напряжение, не про
межличностный спор, хотя оба могут начинаться с одного инцидента —
если в основе business/user tradeoff, а не столкновение характеров,
это `leadership-ethics`, не `conflict-resolution`.

`self-leadership` работает в фоне для всех остальных четырёх — без
управления собственным временем/энергией не хватит ресурса провести
трудный разговор, разрешить конфликт или менторить качественно.
Использовать первым при перегрузке, не последним.

`mentorship` — четыре режима, не один: coaching растит суждение
(вопросы), advising просто передаёт ответ. Не подменять coaching
готовым решением, если цель — развитие человека, а не скорость
здесь-и-сейчас.
