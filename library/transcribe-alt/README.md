# Альтернативы транскрибации — советчик по выбору

Блок `transcribe` ставит `whisper-windows-mcp` по умолчанию (локально, GPU
Vulkan, без облачного ключа — лучше всего подходит Windows-пользователю без
подписок). Здесь — что взять вместо, если дефолт не подходит.

## Кандидаты

| Инструмент | Развёртывание | Ключ | Когда выбрать вместо дефолта |
|---|---|---|---|
| **mcp-server-whisper** (arcaputo3) | Облако (OpenAI Whisper/GPT-4o API) | нужен `OPENAI_API_KEY` | Нет GPU или не Windows; нужен поиск и чат по содержимому аудио, не только текст расшифровки; точность важнее приватности |
| **whisper.cpp** (ggml-org) | Локально, C/C++ без Python | не нужен | Уже используется как движок под другой MCP или встраивается напрямую в свой пайплайн без готовой MCP-обёртки — движок, а не готовый инструмент для агента |

## Когда переключаться с дефолта

- Данные нельзя обрабатывать локально по мощности (нет GPU, слабое CPU) —
  `mcp-server-whisper`, но учесть: аудио уходит на сторону OpenAI, не для
  конфиденциальных записей.
- Не Windows (macOS/Linux) — `whisper-windows-mcp` не подходит по названию и
  сборке, взять `whisper.cpp` напрямую или искать Linux/macOS-обёртку поверх
  того же движка.
- Нужна не транскрибация, а движок для собственной интеграции (свой скилл,
  свой пайплайн) — `whisper.cpp` как библиотека, без MCP-прослойки.

Лицензии: `mcp-server-whisper` не указана явно, `whisper.cpp` — MIT.
