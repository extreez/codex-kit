# URL → markdown для агентов — советчик по выбору

Задача: получить страницу в виде чистого текста без ручного парсинга HTML.
Для простого случая «прочитать одну страницу» это уже умеет
`mcp__Claude_Browser__get_page_text`/`read_page` и встроенный `WebFetch` —
отдельный инструмент из этого library нужен только для того, чего они не
умеют: массовая конвертация, тяжёлый JS-рендеринг, обход anti-bot на уровне
скрейпа (для того, что относится к обходу защиты конкретно — см.
`library/web-scrape-stealth`).

## Кандидаты

| Инструмент | Лицензия | Ключ | Особенность |
|---|---|---|---|
| **curl.md** (wevm) | MIT | не нужен | Простой конвертер URL→markdown, экономия токенов, портативен |
| **Firecrawl scrape** | не указана явно (open-source, 176k★) | нужен после бесплатного лимита | JS-рендеринг, обход части anti-bot, PDF/DOCX/XLSX-парсинг встроен |

## Рекомендация

**curl.md по умолчанию** — бесплатно, без ключа, ставится как есть, покрывает
большинство статических/серверно-рендеренных страниц. Переходить на
**Firecrawl**, когда страница требует выполнения JS для показа контента
(SPA без SSR) или massoвый краулинг сайта целиком, а не разовая страница.

## Установка

`curl.md`: wevm/curl.md, инструкция в README репозитория.
Firecrawl: `firecrawl.dev`, MCP-сервер + API-ключ, use-case «AI MCPs» на
сайте описывает конкретные сценарии (search/scrape/parse/monitor/interact).
