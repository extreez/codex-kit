# Stealth-браузер (обход anti-bot) — советчик по выбору

Не блоки codex-kit — три внешних инструмента для случаев, когда обычный
браузер (`mcp__Claude_Browser__*`) или `curl.md`/Firecrawl упираются в
Cloudflare/reCAPTCHA/fingerprinting. Ставить только когда обычный доступ к
странице реально блокируется — для простого чтения страницы отдельный
stealth-браузер избыточен.

`lightpanda` (Zig, в 16 раз легче Chrome) исключён из рассмотрения по решению
пользователя: лицензия **AGPL-3.0** обязывает открывать код при встраивании в
сервис — юридический риск для коммерческого проекта.

## Кандидаты

| Инструмент | Язык/движок | Лицензия | Формат |
|---|---|---|---|
| **CloakBrowser** | C++-патчи над Chromium | MIT-обёртка / коммерческий бинарник v148+ | Готовый бинарник, обход Cloudflare/reCAPTCHA, spoofing отпечатков |
| **obscura** | Rust, headless с нуля | Apache-2.0 | Лёгкий (30 МБ), MCP-сервер «из коробки» |
| **Botasaurus** | Python-фреймворк | MIT | Библиотека для написания кода, не готовый MCP — обход Cloudflare/Datadome |

## Рекомендация

Нет явного победителя — три разных компромисса:

- **obscura** ближе всего к «поставил MCP и работает»: разрешительная лицензия
  (Apache-2.0), не требует писать код. Разумный дефолт, если нужен именно
  MCP-сервер для агента.
- **CloakBrowser** сильнее по обходу защиты (отдельные патчи под конкретные
  антибот-системы), но новые версии бинарника платные — оценить, оправдывает
  ли задача подписку.
- **Botasaurus** — выбор, если сценарий уже подразумевает написание
  Python-кода (пакетный скрапинг, не разовый агентский вызов), не для прямой
  MCP-интеграции.

## Установка

Каждый ставится независимо, README своего репозитория:
CloakHQ/CloakBrowser, h4ckf0r0day/obscura, omkarcloud/botasaurus. Ни один не
входит ни в один стек codex-kit по умолчанию — осознанный выбор под
конкретный проект, не установка «на всякий случай».
