# Краулер/рэнк-трекер для живых SEO-данных — советчик по выбору

Ничего из этого файла не установлено и не подключено — `.mcp.json` не
тронут. Это справочник на случай, если блокам стека `seo` понадобятся
живые данные (реальные позиции, реальный обход сайта), которых промпт-
методология сама по себе не даёт.

## Бесплатные/self-hosted (дефолт-кандидаты)

- **SerpBear** — self-hosted рэнк-трекинг: свой сервер, свои ключи от
  поисковых API, без подписки на сторонний SaaS. Кандидат для рэнк-
  трекинга, если проект готов держать свой сервис.
  Репозиторий: https://github.com/towfiqi/serpbear
- **LibreCrawl**, **SEOnaut** — открытые технические SEO-краулеры,
  альтернатива Screaming Frog (платный) без лицензии. Обходят сайт,
  находят проблемы, которые `seo-audit` в промпт-режиме находит только на
  выборке страниц, а не на всём сайте разом.
  Репозитории: https://github.com/PhialsBasement/LibreCrawl,
  https://github.com/stjudewashere/seonaut

## Платные API (богаче данными, требуют подписку)

- **DataForSEO** — метрики позиций/бэклинков/ключевых слов, встречается
  как повторяющийся выбор источника в нескольких материалах
  (see-research отчёт: on-page-seo приложение, habr-обзор инструментов,
  подразумевается в open-seo). Кандидат на единую MCP-обвязку, если блоки
  стека будут тянуть живые данные вместо промпт-оценки.
  Сайт: https://dataforseo.com (открытого репозитория нет, коммерческий API)
- **SerpApi** — API для скрейпинга SERP напрямую, официальный источник
  данных позиций и структуры выдачи.
  Сайт: https://serpapi.com (открытого репозитория нет, коммерческий API)
- **Google Search Console API** — бесплатный (в отличие от двух выше),
  официальный источник данных по индексации и кликам напрямую от Google.
  Не требует стороннего API-ключа, только OAuth к своему аккаунту —
  стоит обвязать в MCP отдельно от коммерческих инструментов, это не
  платная зависимость.
  Документация: https://developers.google.com/webmaster-tools/search-console-api-original

## Когда какой ставить

- Нужен только рэнк-трекинг без глубокого анализа — `SerpBear`.
- Нужен обход всего сайта технически (замена ручному `curl` по страницам
  в `seo-audit`) — `LibreCrawl`/`SEOnaut`.
- Нужны данные конкурентов (ключевые слова, бэклинки, трафик) — только
  платные API, бесплатной замены с той же глубиной в источниках не
  нашлось: `DataForSEO` или `SerpApi`.
- Нужны собственные данные индексации/кликов сайта — `Google Search
  Console API`, всегда в приоритете перед платными аналогами для этой
  конкретной задачи (это первоисточник данных, не оценка от третьей
  стороны).

## Как это соотносится с блоками

`seo-audit` работает без всего перечисленного (см.
`library/seo-audit-approach`). `seo-content`/`seo-offpage`/`seo-local`
методологически не завязаны на конкретный API — если пользователь заведёт
любой из инструментов выше, эти блоки используют живые данные там, где
сейчас предполагают ручной сбор (например, keyword research в
`seo-content` — вручную через SERP-анализ, с `DataForSEO` — автоматически
через MCP-вызов).
