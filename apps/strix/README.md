# Strix — автономный пентестер

Обёртка над [usestrix/strix](https://github.com/usestrix/strix): агент сам ищет и
эксплуатирует уязвимости в песочнице, даёт отчёт. Тяжелее ручной красной команды
(`sec-attack`), берётся для широкого автономного прохода.

Это репо-инструмент каталога: живёт в `apps/`, результат пишет в проект. В стек
`secure` по умолчанию не входит — включается руками, когда нужен.

## Установка

Нужен Docker (Strix поднимает песочницу своим образом).

Официальный установщик:

```bash
curl -sSL https://strix.ai/install | bash
```

Или через PyPI (пакет `strix-agent`):

```bash
pipx install strix-agent
```

`curl | bash` исполняет код из сети — сначала посмотри, что качаешь (правило
DE-2). Проверь источник, потом запускай сам.

## Ключи

Strix ходит в модель. Ключи — через переменные окружения, не в код (SE-1):

```bash
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="твой-ключ"
```

## Запуск через обёртку (с предохранителем)

```bash
./run.sh <путь-к-своему-проекту>
```

Обёртка проверяет: цель — локальный каталог, не URL и не чужой адрес; ключи и
Docker на месте. Отчёт кладёт в `<проект>/docs/security/`.

Предохранитель: сканируй только свой проект. Не натравливай Strix на чужое.

## Запуск напрямую (без обёртки)

```bash
strix -n -t ./ --scan-mode quick     # headless, быстрый режим
strix --target ./app-directory       # интерактивно
```

## Без codex-kit

Strix не нужен каталог. Ставится и работает сам по себе:

```bash
git clone https://github.com/usestrix/strix
# дальше по README самого strix: установка, ключи, strix --target ./твой-проект
```

Или просто установщиком выше и `strix --target <путь>` — репозиторий каталога
не требуется вовсе. `apps/strix/` здесь нужен только для предохранителя-обёртки и
единого места отчётов; сам Strix от него не зависит.
